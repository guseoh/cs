## #131 — fix(sre): OPS-AUTO-007 SSM 승인 파라미터 fallback 보강

**판정:** ENV_VAR fallback 가설 보강; 실제 적용 분리 관련 기록: [PWL-0029](../../lessons/PWL-0029.md), [PWC-0068](../../decisions/PWC-0068.md)。 [원본](https://github.com/guseoh/pawcycle-commerce/pull/131)

## #133 — fix(sre): ENV_VAR 의존 제거 및 SSM positional 전달

**판정:** ENV_VAR 제거·제한된 positional5개 전환 관련 기록: [PWL-0029](../../lessons/PWL-0029.md)。 [원본](https://github.com/guseoh/pawcycle-commerce/pull/133)

v3/v4 실제 fallback이 self-reference export로 materialize돼 set-u에서 exit1을 유발할 수 있었다. ENV_VAR/legacy fallback을 제거하고 Operation+4SHA를 quoted argv $1~$5로 고정했다. injection-shaped 값 및 허용 위치 밖 interpolation 거부를 검증했지만 실제 Agent 경로의 잔여 exit1은 #134/#135가 다룬다.

**원본이 보고한 계약·검증·한계 추출:** 아래는 공개 Issue/PR의 당시 진술이다. 이번 Wiki 조사에서 제품/운영 검증을 재실행한 결과가 아니다. 승인·실행·병합 상태는 위 판정 및 manifest의 시각·SHA와 구분한다.

### 원본 진술: 목적과 범위

- 목적: Production SSM v3/v4에서 5개 parameter materialization이 preflight를 exit 1로 종료시키는 결함을 최종 수정한다.
- 변경 범위: SSM Document parameter 전달 방식, 직접 보호 validator, Production contract validator, rollback Runbook delta.
- 제외 범위: AWS 실행, GitHub Production Environment 변경, 실제 SSM preflight/deploy, DB migration, Scheduler, 제품 코드.

### 원본 진술: 결정과 영향

- Production 증거: v4 generated `_script.sh`에 heredoc wrapper가 정확히 존재했지만 fallback이 `export SSM_Operation="$SSM_Operation"` 형태로 materialize되었고, 실제 Run Command는 stdout 없이 exit 1이었다. 동일 script에 5개 값을 직접 주입하면 preflight가 완전 PASS했다. v3/v4 모두 같은 self-reference fallback 형태를 회귀 fixture로 고정했다.
- 수정 이유: `interpolationType: ENV_VAR`와 fallback은 agent materialization 경계에서 독립적인 fallback 값을 만들지 못하므로 제거했다. 정확히 제한된 5개 parameter를 quoted Bash positional argument로 전달하고 `$1`~`$5`로 읽도록 전환했다.
- 안전성: Operation과 4개 SHA의 기존 allowedPattern을 유지하고, validator가 injection-shaped 값 거부와 exact argv 위치 외 interpolation 금지를 검증한다. 승인 경계와 deploy.sh 보호 로직은 변경하지 않았다.

- 실패·미실행과 이유: 실제 AWS/Production preflight·deploy는 저장소 변경 범위 밖이므로 실행하지 않았다.

**판정:** 사후처리·운영 projection·Billing correction7개 관련 기록: [PWC-0070](../../decisions/PWC-0070.md), [PWC-0016](../../decisions/PWC-0016.md)。 [원본](https://github.com/guseoh/pawcycle-commerce/pull/138)

최종 본문은 correction7개 중심으로 수정됐으므로 API007·V16~V19·파일diff에서 원래 범위도 복원했다. 취소/반품/환불/배송/DB알림/Admin운영을 추가하고 server availableActions·권한/CSRF·동일회원404를 유지한다. PROCESSING/UNKNOWN은 Provider write재실행 대신 query대사, retry는 명시경로·새Payment RESERVE, Billing성공membership재평가, 반품projection동일성·문자길이·action한도·0원refund무Provider/V19를 보강했다. remote all lanes 성공을 확인한 반면 local datasource부재 migration미실행·별도제안미처리는 남긴다.

# PawCycle Wiki를 AI 검색 전용 영속 Project Memory로 운영한다

## Context
사용자는 과거 PawCycle의 설계와 구현을 AI-assisted 방식으로 진행하며, 채팅 기억과 각 Codex 세션만으로는 최초 결정의 이유, 대안, 실패, 후속 수정을 장기 복원하기 어렵다는 한계를 확인했다. 기존 주요 사건 선별 기록은 최초 PR과 작은 결정·보류·수정의 맥락을 놓칠 수 있다.

## User-confirmed decision — 2026-11-03
이 Wiki는 사람이 읽는 보고서가 아니라 **ChatGPT와 Codex가 읽는 영속적 프로젝트 기억 저장소**다. 과거에는 최초 PR부터 모든 원본을 **번호 순으로 상세 검토**하고, 원본별 처리 결과와 결정/교훈/사건/기존 기록 링크 또는 별도 기록 불필요 이유를 남긴다. 주제를 임의로 선택해 건너뛰지 않는다. 앞으로는 설계 초안, 검토한 대안, 사용자 승인 결정, 보류·기각, 구현·테스트, 실패·중단, 후속 수정·운영 검증까지 **과정 자체를 지속 기록**한다.

사용자가 “예전에 왜 이렇게 설계했나?”, “어떤 실패가 포트폴리오에 적합한가?”라고 묻는다면 ChatGPT/Codex가 Wiki를 검색하여 **당시 근거와 후속 변경을 연결해 설명**한다. 이때 현재 코드와 Production을 별도로 재검증하고 사실·가설·미확인을 구분한다.

## Alternatives and constraints
- **채팅 메모리만 유지:** 세션 교체와 기억 요약 손실 때문에 불충분하다.
- **중요 주제만 샘플링:** 작지만 의미 있는 역사적 선택/실패가 빠지므로 소급 전수 조사에는 부적합하다.
- **모든 원본마다 거대한 새 문서:** 중복과 검색 노이즈가 커지므로 선택하지 않는다. 원본별 disposition은 반드시 남기되 사건은 ledger/journal로, 재사용할 판단은 Decision/Lesson으로 묶는다.
- **과거 이력을 최신 사실로 덮어쓰기:** 당시 의도와 현재 상태를 혼동하므로 금지한다. supersession과 시점별 근거를 보존한다.

## Execution and verification boundary
PawCycle source-of-truth는 최신 main 승인 요구·코드·테스트·운영 원본이다. Wiki는 역사적 결정과 증거를 탐색하는 색인이다. ChatGPT/Codex가 로컬 Obsidian 파일이나 다른 세션을 자동으로 읽는 것은 아니며, 접근 가능한 GitHub Markdown 또는 명시적 인계가 필요하다. Wiki는 공개 저장소이므로 비밀값·고객 정보·비공개 대화 원문은 기록하지 않는다. 새 기록의 저장은 도구 권한과 별도 Git/PR 절차를 따라 리뷰 가능하게 진행한다.

## Provenance
2026-11-03 사용자가 대화에서 기록의 목적, 모든 과거 원본 검토, 앞으로의 지속 기록, AI 검색과 포트폴리오 재구성 요구를 명시적으로 확정했다. 이 문서는 **사용자 확정 정책의 기록**이며 과거 500개 원본을 이미 모두 심사했다는 주장이 아니다.

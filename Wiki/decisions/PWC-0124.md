# MVC 입력 오류와 Frontend 도메인 오류는 실제 wire 경계에서 보호한다

## Context

Recommendation/Interaction/Product가 공통 Advice 범위에서 빠져 framework binding 오류가 catch-all500으로 처리됐다.

## Decision and alternatives

정확한 API 패키지를 공통 Validation Advice에 포함하고 Frontend의 선택적 fieldErrors와 domain code를 검증·보존한다. ProductController의 테스트 호환 재호출/미사용 overload를 제거하고 실제 MVC/Security 회귀로 확인한다.

## Consequences and verification limits

추천 알고리즘·인증 정책·DB 의미는 바꾸지 않는다. mock 직접 호출 성공은 HTTP binding 성공을 대신하지 않으며 테스트 순위를 맞추기 위한 타 상품 일괄 상태 변경도 피한다.

저장소 구현·CI·당시 보고를 대조한 역사 기록이다. 이번 작업은 제품 테스트·Provider·운영/DB를 재실행하지 않았다. source별 최초 실패·수정·최신 HEAD CI와 리뷰 한계는 아래 대장을 따른다.

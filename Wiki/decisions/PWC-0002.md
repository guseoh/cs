# OCI A1 acquisition worker is guarded and time-bounded

## Context
OCI Tokyo Always Free A1 capacity can be unavailable. Retries must not create duplicate or billable instances due to uncertain API outcomes.

## Decision
Prepare a disabled-by-default single-Host worker with persistent launch intent, strict capacity/quota/cost/network checks and manual approval gates. The PR targeted one A1 instance (2 OCPU, 12 GiB RAM, 50 GB boot volume), bounded to 2026-11-07 KST; it defines shutdown after 2026-11-08 00:00 KST.

## Rejected alternatives
- Unbounded retries or duplicate launch after uncertain HTTP 429.
- Relax eligibility/billing gates to force a new instance.
- Automatically assume source merge authorizes live cloud mutation.

## Consequences and constraints
Operator must verify tenancy, Always Free eligibility, IAM, execution Host and approval lifetime before use. A worker on an expiring Host cannot guarantee capacity acquisition. No account mutation is authorized by this Wiki.

## Implementation/verification
[PR #496](https://github.com/guseoh/pawcycle-commerce/pull/496) merged on 2026-11-03. Isolated tests and CI succeeded per PR, but actual OCI LaunchInstance, Host installation, IAM and account preflight **NOT RUN**.

## Provenance
Merged PR #496 with explicit scope and caveats.

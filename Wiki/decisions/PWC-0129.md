# A1 단기 스케줄러는 조회 호출만 옮기고 실제 실행 연속성을 별도로 검증한다

## Context

GitHub5분 schedule은 지연/누락될 수 있어 단기 외부 스케줄러가 필요했지만 dispatch204는 OCI 조회 성공이 아니었다.

## Decision and alternatives

#503 최종 병합은 Cloudflare Free Cron→고정 main workflow_dispatch(check), 실제 호출 시각 기반 진행 중/최근 실행 중복 억제·stale_check와 식별된 run 집계를 선택했다. 기존 Python OCI 조회·Discord·Issue는 유지하며 외부 Heartbeat2개는 제거하고 Slack은 검토만 남겼다.

## Consequences and verification limits

11월6~7일까지 한시 사용 계획이며 Worker 기본 disabled다. stale_check는 독립 Discord 장애 경보가 아니다. PAT 범위/만료·CPU·실 Cron·조회·알림/연속성과 중단은 운영 Gate이며 이번 저장소 병합은 Cloud 배포/Secret 생성·등록·VM 생성 승인이 아니다. Open #502의 Heartbeat안은 별도 역사로 보존한다.

저장소 구현·CI·당시 보고를 대조한 역사 기록이다. 이번 작업은 제품 테스트·Provider·운영/DB를 재실행하지 않았다. source별 최초 실패·수정·최신 HEAD CI와 리뷰 한계는 아래 대장을 따른다.

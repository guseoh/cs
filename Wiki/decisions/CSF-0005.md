# Review Network Pilot diagrams as one complete batch, not five serial approvals

## Context

The accepted [CSF-0004](CSF-0004.md) set five concept-specific Network visualizations. After N-01 was implemented, the user explicitly rejected repeatedly stopping for individual review, because that workflow delayed the completion of the Network area.

## Decision

Implement N-01 through N-05 together and perform one consolidated technical/visual and contract review. Respect the approved subject-specific visual forms and do not make unnecessary animation or control changes. Do not interpret bulk execution as authorization for automatic production data writes or merging without validation.

## Rejected alternatives

- Seeking user review after every individual TCP, DNS, HTTP visualization.
- Forcing a generic diagram engine or an unreviewed mass rewrite of 127 Network Concepts.

## Consequences and constraints

Use existing TCP handshake and Sliding Window evidence where valid. Add bounded network-core renderer identifiers only with matching frontend/backend validation. Preserve stable keys, personal data, reference integrity, RFC semantics and editorial light/dark readability. Distinguish completion of these five pilots from the full 127-concept Network content audit required in Issue #278.

## Implementation/verification

[CSForge PR #298](https://github.com/guseoh/csforge/pull/298) now contains all five Reader renderers and four new canonical Markdown visualization declarations, with frontend/backend allowlists for four fixed network-core examples. The [Network Pilot Pack browser QA run](https://github.com/guseoh/csforge/actions/runs/42452923551) passed 5 diagrams, 2 themes, 2 desktop widths, and every interactive step; 20 audited figure variants and 0 page errors. Full backend Repository Validation was still in progress when this record was prepared. The PR is Draft/unmerged; no production Import or protected personal-data validation is claimed.

## Provenance

The user explicitly changed the preferred execution cadence on 2026-11-08; GitHub code and workflow runs provide separate implementation evidence.

# Adopt the 7-course, 34-unit Spring learning curriculum and restart at topic 01

## Context

[BLR-0009](BLR-0009.md) established a selective, backend-focused Spring Framework / Spring Boot learning approach. A specific curriculum was then proposed with seven course tracks, 34 concept units, 17 priority deep dives, low-value lecture exclusions, and modern API/operations supplementation. The draft was stored separately as [BLK-0002](../knowledge/BLK-0002.md).

## Decision

On 2026-11-08, the user explicitly confirmed the proposed **7-track / 34-unit curriculum** and the 17 prioritized deep-dive units as the learning syllabus. The full topic list, depth classifications, and editorial cuts/additions are in the published [BLK-0002 curriculum](../knowledge/BLK-0002.md).

Study will **start over in a new ChatGPT session from unit 01, object-oriented design and IoC/DI**. An earlier article about the topic does not count as confirmed completion. All remaining topics follow the accepted unit order while depth stays proportional to implementation, system understanding and backend practice.

Use the lecture PDFs as code/figure/context references rather than a mandatory lecture-by-lecture explanation. Skip unnecessary XML configuration exercises, Thymeleaf syntax and repeated teaching-domain implementation; keep enough Servlet/MVC evolution to explain modern Spring MVC. Provide substantive Spring runtime explanations, current official-source checks and Korean engineering references. No mandatory quizzes, comprehension checks or separate coding exercises.

## Rejected alternatives

- Continue directly from unit 02 based on an earlier draft explanation: **not selected**. Start fresh at unit 01.
- Retain a provisional detailed roadmap after explicit user confirmation: **not selected**.
- Interpret acceptance as a requirement to implement every PDF sample or fully master every topic equally: **not selected**.

## Consequences and constraints

This approval settles the **curriculum and default study sequence**, not the factual accuracy of every prior PDF mapping or every framework-version detail. Confirm version-sensitive statements against current Spring documentation when each topic is taught. No project software, code, operational environments, or separate Java/JPA/DB/Security curricula are changed by this decision.

## Implementation/verification

The user confirmed the syllabus in conversation; no course completion, tests, Spring Boot application execution or independent re-audit of all 87 PDF contents is claimed. The referenced 87-PDF / 2,206-page count comes from earlier analysis, not from this acceptance action.

## Provenance

Direct user approval, summarized for a public Wiki without copying the private lesson PDFs or conversation.

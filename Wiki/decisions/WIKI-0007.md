# 프로젝트 공통 규칙을 통한 Obsidian 연동

## 배경
공통 장기 기억을 특정 IDE에 종속시키지 않고 여러 개발 에이전트 및 채팅 환경에서 활용하려 한다. 공식 스킬은 Obsidian 문법과 CLI 사용 지침을 제공하지만 Vault 접근 권한과 기록 정책을 자동 부여하지 않는다.

## 결정
프로젝트 루트 AGENTS.md를 공통 진입점으로 사용하고 상세 운영 정책은 [Wiki 실행 계약](../AGENTS.md)에 유지한다. 일반 채팅 프로젝트에서는 지원되는 프로젝트 지침에 같은 계약을 참조한다. 허용된 로컬 환경에서는 공식 스킬과 CLI를 활용하며, 접근이 불가능하거나 최신성 확인이 어려우면 GitHub 원문을 사용한다. 기존 사용자 전역 규칙을 삭제하지 않고 불필요한 신규 전역 파일도 만들지 않는다.

## 선택하지 않은 대안
에이전트마다 정책 전체를 복제하면 규칙 변경 시 드리프트가 생긴다. 별도 MCP 서버나 Vault 복제는 현재 요구의 필수 요소가 아니며 도입하지 않는다. 프로젝트 범위 밖의 작업에는 별도 지침이 필요할 수 있다.

## 결과와 제약
기존 기록 모드, 원본 권위, PR 승인 및 검증은 유지한다. 읽기 권한과 쓰기 권한, 스킬 활성화, CLI 실행, 원격 병합과 로컬 동기화는 서로 다른 상태이다. 개인 환경 경로와 비공개 정보는 공개 문서에 넣지 않는다.

## 구현 및 검증
사용자는 Windows 로컬 CLI의 버전·Vault 조회 성공과 Claude Code 및 Antigravity의 공식 스킬 활성화를 보고했다. Codex는 마켓플레이스 등록까지만 보고되었으며 실제 플러그인 활성화와 모든 앱의 종단간 접근 검증은 미확인이다. 이번 규칙 변경의 CI·병합·로컬 동기화도 별도 확인해야 한다.

## 출처와 결정 경위
2026-11-27 사용자가 여러 앱에서 Obsidian을 사용하고 프로젝트 공통 규칙에 반영하는 방식을 승인했다. 공식 스킬 저장소와 커넥터 문서는 스킬과 CLI의 역할을 설명한다.

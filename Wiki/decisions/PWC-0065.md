# 관측 metric은 commit 결과를 따르고 scrape DB 비용을 별도 평가한다

Actuator health/prometheus와 bounded scope/operation/result만 expose한다. 개별 식별자는 tag 대신 로그로 추적한다. cleanup 성공 metric은 메서드 반환이 아닌 transaction completion 기준으로 기록해 commit 실패를 failure로 관측한다.

현재 row/candidate gauge는 source-of-truth DB를 scrape마다 indexed COUNT4회 조회한다. cache·refresh cadence·query-timeout 새 정책은 승인 범위 밖이라 Phase A에서는 잔여 위험으로 수용하고 local Phase B에서 비용을 측정했다. DB 장애와 scrape 가용성 결합은 해결된 것으로 쓰지 않는다.

선택형 Compose override, loopback, 내부 scrape·proxy404·datasource/dashboard provisioning과 실제 metric 변화가 local에서 보고됐다. Production 배치·sizing·cadence는 별도다.

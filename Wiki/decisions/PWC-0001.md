# Separate repository readiness from OCI production activation

## Context
CI green, image publication and merged Host Pull CD code cannot prove cloud identity, DB consistency, recoverability or current running production.

## Decision
Keep automated application deployment and zero-downtime rollout deferred until explicit operational approval and fresh runtime/recovery evidence. Evaluate each deployment target independently.

## Rejected alternatives
- Automatically activate Host Pull CD when its CI passes.
- Treat GHCR image publication as application deployment.
- Reactivate retired AWS operation contracts as if they apply directly to OCI.

## Consequences and constraints
Never claim Production Verified from GitHub-only evidence. README and ops overview disagree about whether OCI app01 is an active target; resolve with fresh OCI facts.

## Implementation/verification
[PR #490](https://github.com/guseoh/pawcycle-commerce/pull/490) merged code but excluded actual OCI install, activation and operating E2E. [Operations overview](https://github.com/guseoh/pawcycle-commerce/blob/main/docs/architecture/production-operations-overview.md) marks CD DEFER/OFF.

## Subsequent implementation and operational boundary
[PR #472](https://github.com/guseoh/pawcycle-commerce/pull/472) and [PR #474](https://github.com/guseoh/pawcycle-commerce/pull/474) subsequently implemented the protected Release Engine and Host Pull CD in source. [PR #486](https://github.com/guseoh/pawcycle-commerce/pull/486)/[#490](https://github.com/guseoh/pawcycle-commerce/pull/490) refined restricted frontend and service-scoped auto paths. The [first OCI transition report](https://github.com/guseoh/pawcycle-commerce/blob/main/docs/reports/OPS-OCI-CD-011/README.md) describes an **actual 2026-10-31 attempted release stopped pre-image-pull**. This is not the same as a fully activated service or verified rollback. Historical ops overview text may predate later operating changes; current live Host evidence must be checked independently.

## Provenance
Merged PR and operational documentation. Present live state unverified.

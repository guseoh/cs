# Subscription command는 실제 잠금·CAS를 보존하고 Entity를 독립 파일로 둔다

## Context

T09는 command/schedule/reconciliation 뿐 아니라 주문 생성·공통 주문/결제 DB 기록·예약까지 같은 원자적 작업 경계였다. 외부 Provider/Billing 복구는 T10 책임이었다.

## Decision

JPA CRUD·typed projection·조건부 mutation 을 기본으로 쓰되 JOIN/LIMIT FOR UPDATE·reservation upsert·version/inventory CAS·snapshot copy 는 필요한 native 의미를 유지한다. replay 우선, parent/scope lock, 대상별 REQUIRES_NEW 와 실패 rollback 을 보존한다. 사용자 후속 결정에 따라 11개 Entity·5개 PK record·mapped superclass 를 top-level 파일로 두고 private field·기존 Lombok/JPA 관례를 따른다.

## Alternatives and interpretation

중첩 ~Rows Entity 컨테이너, 무타입 insert(Object), 단순 이름만 바꾼 native wrapper, candidate Tx 안 unique exception catch-and-continue 를 제외했다. Proposed ADR 만으로 구현된 lock 정책을 소급 변경하지 않는다.

## Consequences and limits

기존 immutable read mapping7개와 command mapping 의 중복은 이유를 명시한다. persist→flush→detach 와 bulk write 뒤 stale state 를 보호한다. 독립 파일 수와 검증 비용을 수용하며 장기 rich-domain 재설계는 별개다.

# Windows Tern 앱 중심 개발 우선순위 전환

> 2026-11-24 [DTD-0009](DTD-0009.md)로 대체된 과거 결정이다. 아래 내용은 2026-11-23 시점의 아키텍처와 검증 상태를 보존한다.

## 배경
Tern은 Tauri 2를 사용한 개인용 Windows 데스크톱 앱이다. 2026-11-23 사용자는 웹 브라우저용 UI를 더 이상 독립적인 개선 대상으로 신경 쓰지 않아도 되며, 데스크톱 앱 반영 여부가 중요하다고 명시했다. 기존 메모·낙서장 통합 편집 변경은 [PR #167](https://github.com/guseoh/dark-todo-planner/pull/167)로 병합되고 [Production CI](https://github.com/guseoh/dark-todo-planner/actions/runs/45135922038)도 성공했으나 설치된 Tern 화면에서 반영 여부를 아직 독립 검증하지 못했다.

## 결정
- 개발·디자인 검토의 **1차 대상은 Windows 데스크톱 앱 Tern**으로 한다. 브라우저 전용 웹/PWA 화면의 독립적 미관 개선과 반응형 세부 조정은 우선순위에서 제외한다.
- 앱 창 크기와 도구 모음, Windows 트레이/종료, 전역 단축키, WebView 갱신, 데스크톱 로그인·업데이트, Markdown 편집·저장·복구를 우선 검증한다.
- 기존 웹 배포 및 React/Vite·Workers/D1을 현재 단계에서 제거한다는 결정은 아니다. 재사용 중인 코드의 안전성, 인증, 접근성, 데이터 무결성, CI 검증은 계속 유지한다.
- Windows 전용 네이티브 앱에 화면을 묶어 별도의 웹 서버 없이 배포하는 아키텍처 전환은 **논의·승인되지 않았다**. 전환이 필요하다면 배포·인증·업데이트·오프라인 동작과 대안을 별도 검토한다.

## 선택하지 않은 대안
- **웹과 Windows를 동일한 UI 우선순위로 유지:** 현재 사용 목표가 Windows 앱 중심이므로 불필요한 브라우저별 디자인 완성도를 높이는 작업은 뒤로 미룬다.
- **웹 코드·Worker를 즉시 제거:** 공개된 Tern 0.2.0의 [main.rs](https://github.com/guseoh/dark-todo-planner/blob/tern-v0.2.0/src-tauri/src/main.rs)는 `WebviewUrl::External`로 운영 HTTPS 출처를 불러온다. 이를 제거하면 Tern 자체가 화면을 표시하지 못하므로 채택하지 않는다.

## 결과와 제약
현재 Tern 0.2.0의 네이티브 셸은 `https://dark-todo-planner.guseoh.workers.dev`를 불러오며 창 닫기를 숨김으로 처리한다. [PR #167 운영 배포 실행](https://github.com/guseoh/dark-todo-planner/actions/runs/45135922038)은 완료·성공으로 확인했다. 따라서 편집기 변경은 원칙적으로 새 EXE 없이도 서버 화면 갱신 후 표시돼야 하지만, 설치된 사용자 PC의 캐시·실제 실행 버전·Tern 화면 반영은 **미검증**이다.

## 구현 및 검증
2026-11-23: GitHub Actions `main` 실행 #45135922038의 Test/Build, Local Worker+D1+Browser smoke, Deploy production 작업이 모두 성공했음을 확인했다. 릴리스 `tern-v0.2.0`의 Tauri 메인 창 외부 URL과 트레이의 `종료` 기능을 소스에서 확인했다. 실제 Windows 실행을 통한 반영 여부는 확인하지 않았다.

## 출처와 결정 경위
사용자의 2026-11-23 Windows Tern 우선 운영 지침을 확정 결정으로 기록했다. 소스 근거는 공개된 Tern 0.2.0 태그, 메모 편집기 PR 및 Production CI 실행이다.

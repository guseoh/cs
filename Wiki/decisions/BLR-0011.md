# Explain project reverse engineering for backend job seekers

## Context

Project analysis supports backend learning and preparation for explaining portfolio projects.

## Decision

Begin with the whole system and the problem it serves. Explain representative request paths from entry points through domain behavior and data changes in language a developer preparing for a first role can follow. Go deeper on portfolio-worthy decisions such as transaction boundaries, concurrency, failure handling and performance when the project provides evidence.

Explain the reason for each important choice, the plausible alternatives and the trade-offs. Separate documented intent from effects observable in code and from inferences. Cite the source revision, identify unverified runtime outcomes and attribute personal contributions only when supported.

## Implementation and verification

The updated skill and an example analysis are under review in [agent-skills PR #10](https://github.com/guseoh/agent-skills/pull/10). This record captures the teaching preference. Installation and runtime behavior remain separate checks.

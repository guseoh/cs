# 초기 AI 리뷰는 한국어·선별 반영·사용자 병합권을 유지했다

## Context
2026-07-05 PR #12(OPS-003)는 한국어 사용자와 PO/TL이 리뷰를 바로 판단하도록 리뷰 언어 지침을 추가했다. 코드 식별자·파일 경로·요구사항 ID·API path·SHA와 P0/P1/P2 표기는 원문을 유지한다. 영어 리뷰를 차단하는 CI나 봇 설정은 이 단계에서 추가하지 않았다.

## Decision
같은 날 #16(OPS-004)은 Codex Review를 유지하면서 CodeRabbit을 PR 요약·라인별 결함·보안·인증/인가·도메인·테스트 누락 검토를 돕는 보조 리뷰어로 추가했다. Codex는 설계·수정 방향 검토를 돕고, CodeRabbit 의견은 사람이 선별한다. 민감한 결제·주문·구독 상태·인증·개인정보 변경은 PO/TL의 직접 재검토 대상이다. 병합 판단은 사용자에게 남겼다.

설정은 `ko-KR`, `assertive`, `auto_review.enabled=true`, `drafts=false`, `auto_incremental_review=true`이며 기본 브랜치 외 추가 대상은 `develop`이었다. `request_changes_workflow=false`, `fail_commit_status=false`여서 이 파일만으로 강제 승인 Gate를 만들었다고 볼 수 없다.

## Alternatives and constraints
AI 지적 전부 수용, 스타일 취향·과도한 추상화 우선, Codex 제거는 선택하지 않았다. 무료 범위·public 저장소·설치 시 selected repository 하나만 허용하는 운영 기준을 뒀다. App 설치·유료 요금제 설정 자체는 이 PR의 변경 범위가 아니며, 체크박스만으로 현재 요금·권한을 증명하지 않는다.

## Implementation/verification
#12는 AGENTS와 보고/인수인계 3개 파일, #16은 설정·AGENTS·PR 템플릿·보고/인수인계 5개 파일을 변경했다. #12는 처음 산출물 validator 실패 후 인수인계 추가로 통과했다고 보고했다. #16의 YAML parser 검증은 `yaml` 모듈 부재로 실행되지 못했고 PowerShell bash 해석 실패는 Git for Windows Bash로 검증했다고 보고했다. 당시 검증을 이번 조사에서 재실행한 것은 아니다.

후속 #17 보고서는 Draft에서 리뷰가 skip됐고 사용자의 Ready 전환 뒤 리뷰가 수행됐다고 기록한다. 공개 리뷰도 존재한다. 이는 당시 Draft 제외 동작의 근거이며 현재 봇 구독·모든 후속 PR 리뷰 성공을 보장하지 않는다.

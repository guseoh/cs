# Use existing GitHub Markdown repository as Wiki source

## Context

Obsidian is already connected to `guseoh/cs`. The goal is for ChatGPT, Work, and Codex to retrieve and update shared records via their available GitHub access, without requiring a direct connection to a local vault.

## Decision

Use Markdown tracked in `guseoh/cs` as the shared Wiki source. Do not introduce a dedicated server, vector DB, graph DB, or embedding index for Phase 1. Agents must explicitly retrieve the needed records and save changes through an authorized GitHub write workflow.

## Rejected alternatives

- Require each AI to connect directly to a local Obsidian directory: not necessary for the intended GitHub workflow.
- Deploy a new remote knowledge service at the outset: extra complexity with no demonstrated retrieval need.

## Consequences and constraints

- GitHub visibility and AI connection permissions affect what can be read or written.
- GitHub state and local Obsidian state can temporarily differ until sync succeeds.
- `AGENTS.md` is an instruction convention, not a mechanism that automatically gives every AI cross-session memory.
- Sensitive and private data must not be stored in this public repository.

## Implementation/verification

Repository existence, public visibility, and multi-device sync guidance were verified on 2026-11-03. The Phase 1 Wiki change remains subject to PR review and merge; local sync was not inspected.

## Provenance

The shared-GitHub choice was directly confirmed by the user in the 2026-11-03 planning conversation. The repository URL is verifiable; the user's original chat confirmation has no stable public link.

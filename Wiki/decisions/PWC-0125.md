# Order 반품 wire와 화면 모델 차이는 전용 consumer adapter에서 정규화한다

## Context

Backend JSON은 returnRequest인데 화면은 return을 읽어 반품 상태·거절 사유 표시가 누락됐다. TypeScript generic은 응답을 변환하지 않는다.

## Decision and alternatives

orderApi.detail 전용 OrderDetailWire와 정규화로 기존 화면 모델을 유지한다. 실제 Backend 직렬화 assertion과 wire를 모사한 adapter 회귀를 함께 둔다.

## Consequences and verification limits

서버 필드 변경·이중 직렬화·공유 HTTP client 확장을 피한다. 목록/반품 command·정책·React 화면을 재작성하지 않으며 실제 Provider/운영 검증과 별개다.

저장소 구현·CI·당시 보고를 대조한 역사 기록이다. 이번 작업은 제품 테스트·Provider·운영/DB를 재실행하지 않았다. source별 최초 실패·수정·최신 HEAD CI와 리뷰 한계는 아래 대장을 따른다.

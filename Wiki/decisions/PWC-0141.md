# AI가 구현하고 사용자는 완성된 코드를 검토하며 설계와 코드를 학습한다

## Context

같은 날 [PWC-0140](PWC-0140.md)으로 "백엔드·인프라 코드는 AI가 보여 준 정답 코드로 사용자가 직접 구현"하기로 했다. 첫 적용 대상(멤버십 재평가 분리)에서 AI가 준 정답 코드에 커넥션 이중 점유와 재평가 유실 결함이 외부 리뷰로 드러났다([PWL-0057](../lessons/PWL-0057.md)).

## Decision

2026-11-19 사용자 결정.

- AI가 다시 백엔드·인프라·스크립트·문서를 모두 구현한다.
- 사용자는 이전처럼 PR만 검토하는 것이 아니라, **완성된 코드를 직접 읽고 검토하며** 설계와 코드를 학습한다.
- AI는 구현을 끝낼 때 사용자가 학습하며 검토할 수 있도록 다음을 함께 제시한다: 읽는 순서, 핵심 설계 결정, 코드가 왜 그렇게 생겼는지, 실패 경계, 테스트가 보장하는 것.
- 제품 정책·설계 선택·병합 위임은 계속 사용자가 결정한다.

## Rejected alternatives

- [PWC-0140](PWC-0140.md) 유지: 정답 코드 자체가 틀릴 수 있고, 사용자가 받아 적는 동안 그 결함을 검증하기 어렵다.
- PR 단위 검토만 유지: 설계와 코드의 학습 깊이가 부족하다.

## Consequences and constraints

- 완성 코드 검토가 학습과 검증을 겸한다. 사용자 검토 지적은 최신 코드와 대조해 판정한다.
- 포트폴리오에서는 "구현은 AI 도움, 설계 결정과 코드 검토는 직접"으로 분담을 밝힌다.

## Implementation/verification

작업 방식 결정이다. 첫 적용은 [PWC-0142](PWC-0142.md) 구현이다.

# Tern 메모 탐색·편집 통합 및 절제된 색상 강조

## 배경
기존 메모 화면은 여러 카드를 나열하며, 실제 Tiptap 3 편집은 별도 수정 모달에만 나타났다. 사용자가 Windows Tern의 메모 목록 화면과 낙서장 편집 화면을 비교한 뒤, 메모 목록에서 곧바로 문서를 편집할 수 있는 UI 시안 구현과 색상 표현의 적절성 검토를 요청했다.

## 결정
사용자가 시안 구현과 색상 표현을 검토한 후 **2026-11-23 운영 반영과 병합을 명시적으로 승인**하여 [소스 PR #168](https://github.com/guseoh/dark-todo-planner/pull/168)을 [Squash 병합 커밋 `d36611b`](https://github.com/guseoh/dark-todo-planner/commit/d36611b063c68adb8b5f7a4e98d48946885bee05)으로 `main`에 병합했다. 다음 UI 구성이 확정됐다.
- 왼쪽은 한 줄 요약 중심의 세로 메모 목록, 오른쪽은 같은 화면에 상시 나타나는 Tiptap 문서 편집 영역으로 구분한다.
- 별도 메모 수정 모달을 거치지 않고 목록에서 문서를 선택하면 제목·내용·Markdown 서식·연결 정보와 메모 색상을 직접 편집할 수 있게 한다.
- 새 메모도 동일한 편집 영역에서 작성하되, 기존 명시적 서버 저장과 로컬 초안·재시도·Markdown 원본 보존 절차는 유지한다.
- 기존 색상 값을 삭제하거나 재매핑하지 않는다. 카드 전체를 채우는 컬러 배경 대신 **얇은 왼쪽 강조선, 선택 행의 절제된 배경색, 문서 헤더의 색상 표식**에 적용한다.
- Windows Tern의 데스크톱 창을 기준으로 작업하고, 좁은 창에서는 목록·편집 영역을 세로로 표시한다.

## 선택하지 않은 대안
- **기존 2열 카드 유지·수정 모달 유지:** 작성 시 읽기·편집 전환이 빈번해 통합 편집 도입 효과가 드러나지 않는다.
- **메모 카드 전체를 색상별로 채우기:** 가독성과 다크 테마의 중립성이 약해지고 장시간 기록 시 시각적 피로가 높아질 수 있어 초기 시안에서는 제외한다.
- **즉각적인 서버 자동 저장 전환:** 두 기기에서 동일한 메모를 사용할 수 있는 만큼 충돌 처리 없이 서버 저장 정책을 바꾸는 것은 위험하다. 초안/수동 서버 저장을 유지한다.
- **Markdown 저장 형식·DB 스키마 변경:** 편집 화면 교체의 범위를 벗어나며 기존 데이터 손실 위험을 높인다.

## 결과와 제약
사용자가 운영 반영을 승인한 기능 변경이지만, Windows 설치본에서의 수동 시각 검사는 별도이며 완료 여부를 주장하지 않는다. 기존 색상 저장·로컬 초안·Todo/프로젝트 연결을 재활용한다. 메모 선택 전환 시 빠른 입력을 보존하도록 로컬 초안 기록을 보완했으나, 실제 Windows Tern의 사용성, 한국어 IME, Markdown 복합 구문 왕복, 다기기 수정 충돌은 별도로 검증해야 한다.

## 구현 및 검증
2026-11-23: [GitHub PR #168](https://github.com/guseoh/dark-todo-planner/pull/168)을 Draft로 생성했다. 구현에는 목록·문서 2열 레이아웃, 색상 강조, 명시적 저장·기존 원본 모드 및 복합 Markdown 서식 미리보기를 포함한다. [GitHub Actions #45139937246](https://github.com/guseoh/dark-todo-planner/actions/runs/45139937246)의 타입·단위·빌드·Worker/D1·Chromium 브라우저 및 반응형 자동 검증은 성공했다. 사용자의 명시적 병합 요청에 따라 `main`에 PR을 병합했다. [Production CI #45140860278](https://github.com/guseoh/dark-todo-planner/actions/runs/45140860278)는 병합 커밋 `d36611b` 기준 빌드·단위 테스트·Worker/D1/Chromium 회귀·Cloudflare Production Worker 배포·운영 헬스 체크 **전체 성공**으로 검증됐다. 실제 Windows 설치본 사용성 및 동기화 충돌 수동 검증은 미완료다.

## 출처와 결정 경위

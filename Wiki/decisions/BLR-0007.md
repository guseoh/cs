# Ubuntu phase 1: theory and direct practice before advanced infrastructure

## Context

The user intends to learn Linux and web-server operation in the context of Java/Spring backend development. The purpose is to understand the operating environment, not to memorize every CLI command or create another large application development project.

## Decision

- Set the **first-phase learning scope** to Linux fundamentals, web-server architecture, and operation of a single Ubuntu server.
- Combine **theory with hands-on Ubuntu exercises** throughout. Learn commands by applying them to real system behavior rather than rote memorization of the full command catalog.
- Keep this a bounded foundation complementary to the Java/Spring backend-first learning priority, not an immediate expansion into broad cloud/platform engineering.

## Rejected alternatives and undecided choices

- Memorize all Linux commands before starting practical work: **not chosen**.
- Advanced multi-server infrastructure, Kubernetes or large-scale orchestration as a phase-one requirement: **out of scope**, not rejected for future study.
- The subsequent user-reviewed curriculum and approval to proceed adopt **no app project during Linux fundamentals**, then a static Nginx page and **minimal reusable no-DB Spring Boot API** as a lab target; this is not authorization to build a substantial new application. See [BLR-0008](BLR-0008.md) and [the roadmap](../knowledge/BLK-0001.md).

## Consequences and constraints

The Linux learning track should teach what commands and configuration reveal about filesystems, permissions, processes, services, HTTP, ports, logs and failure recovery. A substantial new product application, database, portfolio scope, deployment target or detailed timeline is not part of this accepted decision.

## Implementation/verification

Learning goals and theory-plus-practice approach were directly confirmed on 2026-11-08. No Ubuntu lab environment, Nginx deployment, test API or completed exercise has been independently verified.

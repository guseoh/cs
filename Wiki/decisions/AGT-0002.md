# AgentLab은 현재 단계의 이론을 깊게 배우고 최소 구현으로 검증한다

## Context

초기 Agent Loop와 Prompt/Context 설명에서는 메모형 짧은 문장·ASCII 도식 반복이 많았고, Prompt Caching, Skills, Context Compression, Tool Security, Hermes의 세부 Prompt Assembly처럼 뒤 단계에서 배울 내용을 앞서 과하게 다루었다. 사용자는 풍부한 이론 설명을 원하지만 단계 간 경계와 읽기 좋은 설명형 글을 중시한다.

## Decision

각 단계는 **현재 구현의 문제 → Agent의 일반 원리 → Spring AI의 표현 → 최소 코드 구현 → 실제 실행과 한계 확인 → 필요할 경우 오픈소스 사례 → 핵심 이해·Wiki 기록 → 다음 문제**의 흐름으로 진행한다. 기능을 먼저 무작정 추가하지 않고, 왜 그 기술이 필요한지 현재의 한계에서 출발한다.

설명은 Java/Spring 개발자에게 강의하듯 **문단을 충분히 연결하는 서술형 글**로 작성한다. 한 줄짜리 메모 문장과 지나치게 많은 코드 블록·화살표 도식은 피하고, 코드는 실제 실행 구조를 설명할 때 사용한다. 용어의 정의, 등장 배경, 유사 개념과의 구별, 현재 단계에 필요한 심화 설명을 포함한다.

한국 IT 기업 기술 블로그·일반 한글 개발 블로그와 공식 문서를 적극 활용한다. 실제 기술 이미지·참고 그림이 도움이 되면 출처를 확인해 함께 안내하고, 해당 주제의 **소제목 바로 아래에 관련 자료를 배치**한다. 링크를 열지 않아도 핵심을 이해할 수 있도록 자료 내용을 본문에서 설명한다.

오픈소스 Agent(Hermes 등)는 개념을 이해한 뒤 **구현 비교 사례**로 살펴본다. 특정 Agent 고유의 설계 결정을 보편적인 필수 구조처럼 가르치지 않는다. 모든 단계 말미에는 자기 말로 설명할 수 있는 **3~5개의 완료 기준**을 제시한다. 필수 퀴즈나 불필요한 과도한 구현을 강제하지 않는다.

## Stage 2 boundary: Prompt & Context

현재 단계에서 깊게 다룰 것은 LLM과 서버 상태의 경계, `Prompt`·`Message`·`ChatOptions`, System/User/Assistant/Tool 역할, Prompt와 Context의 개념적 차이, Token/Context Window 기초, Prompt/Context Engineering의 기본적인 구별이다.

실습은 `SystemMessage`와 `UserMessage`로 `Prompt`를 만들어 `ChatClient`에 제공하는 최소 변경만 수행한다. 파일 접근 불가와 별도 HTTP 요청 사이의 대화 이력 부재를 확인하며, 해결은 각각 3단계 Tool Calling 및 6단계 Conversation & Session으로 미룬다.

Context Compression·Context Rot 대응·Prompt Caching·Skills의 구체 구현·심화 Tool Security·Hermes의 상세 Context 생명주기는 관련된 후속 단계에서 다룬다. 관련성이 있다는 사실만 간단히 연결할 수 있다.

## Rejected alternatives

- 모든 기술 개념에 동일한 깊이의 소제목과 억지 도식을 배치하는 방식.
- 짧은 문장 및 'A vs B' 구문을 기계적으로 반복하는 메모형 학습 노트.
- 본문과 직접 관계된 참고 링크를 마지막에만 일괄 나열하는 방식.
- 현재 주제와 관계없이 후속 로드맵 기능을 먼저 구현하는 방식.

## Consequences and constraints

설명의 깊이는 **현재 문제를 이해하는 데 필요한 내부 원리의 깊이**로 판단한다. 로드맵 범위 확장을 학습 깊이와 동일시하지 않는다. 중요한 사실·제안·미검증 코드·실행 결과를 구분하며, 검증되지 않은 구현을 완료 처리하지 않는다.

## Implementation/verification

규칙은 대화에서 사용자 피드백을 받아 확정되었다. 설명 방식에 관한 결정이지, 2단계 코드 반영·기능 테스트·Wiki 학습 문서 완성을 인증하는 기록은 아니다.

## Provenance

사용자 확정 학습 방법의 공개 가능한 요약. 비공개 대화 원문은 옮기지 않았다.

# Desktop UI는 승인된 시안 변화와 fixture·실인증 검증 범위를 함께 남긴다

## Context

상품 위계·구매 행동·오류 복구를 개선하되 기존 Commerce와 모바일·Admin·데이터 의미를 혼합하면 검증 범위가 흐려졌다.

## Decision and alternatives

Daily Orbit G0~G5 공개 화면, G6 인증 후 화면 후보, 고객 오류 복구를 범위별로 다뤘다. 최종 #495의 승인 R3는 R2의5열을3열 balanced/4열 regular로 대체하고 실제2단 트리·keyboard/focus·filter draft/apply를 보호한다.

## Consequences and verification limits

#466/#469 Open 원본과 대체 병합을 중복 계산하지 않는다. 합성 fixture·loopback 캡처·CI는 실제 인증/결제/운영 데이터나 모바일 전체 검증이 아니다. #495 reviewer 예외는 해당 PR에만 적용되며 모든 향후 PR 승인으로 일반화하지 않는다.

저장소 구현·CI·당시 보고를 대조한 역사 기록이다. 이번 작업은 제품 테스트·Provider·운영/DB를 재실행하지 않았다. source별 최초 실패·수정·최신 HEAD CI와 리뷰 한계는 아래 대장을 따른다.

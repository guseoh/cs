# Admin Catalog는 기존 API의 변경 필드 PATCH와 명시적 할당으로 관리한다

Admin Catalog workspace는 Backend 계약을 따르며 dirty PATCH와 허용된 null clear, SKU code 불변, inactive/system Category·Brand 선택 차단을 적용했다. CSRF mutation과 generation guard, 저장 성공 뒤 refresh 실패를 구분한다. 기존 할당 GET이 없을 때 현재값처럼 꾸미지 않고 전체 교체/지정 할당임을 명시했다.

#243 최초 Node100/100과 disposable Admin→Customer readback Browser 결과는 있지만 correction 뒤 전체 재실행은 없었다. upload·inventory·Admin returnTo·실제 오류/race 주입은 미검증이다. #245 readback 확장 후 #246 병합 뒤 category stale assignment 등의 추가 리뷰가 나타났으므로 최초 구현의 영구 해결로 보지 않는다. UI revert는 이미 저장한 데이터를 되돌리지 않는다.

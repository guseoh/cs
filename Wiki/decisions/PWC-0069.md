# Admin Catalog는 RBAC·상태 전이·공개 SKU와 구독 적격성을 분리한다

#136은 ADMIN 인가와 기존 session/CSRF를 사용하고 role 변경·실계정 provisioning은 제공하지 않았다. Product는 DRAFT 생성 후 DRAFT→PUBLIC/PUBLIC→INACTIVE/INACTIVE→PUBLIC만 허용하며 동시 PATCH는 row lock으로 직렬화한다.

Category active가 Product 공개 상태를 연쇄 변경하지 않는다. SKU ACTIVE는 공개 projection만 제한하고 subscribable은 구독 적격성으로 독립이다. ACTIVE SKU가 없어도 PUBLIC Product는 빈 SKU 배열로 남는다. me.role만 additive이며 login 응답은 유지한다.

처음 categoryId nullable 계약은 #137에서 신규 active실Category 필수로 변경됐다. legacy는 비활성 내부 system Category로 backfill해 이력을 보존한다. V12/후속 DDL의 운영 적용과 ADMIN 생성은 저장소 테스트와 별도다.

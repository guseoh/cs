# Toss Test는 명시 opt-in과 서버 금액 대조로 준비하며 실결제와 구분한다

Toss v2 Test adapter는 Test 활성 flag와 유효 Test secret이 함께 있을 때만 선택한다. 기본은 local fake이며 미구성은 unavailable/fail-closed다. redirect amount보다 Backend Checkout amount를 권위로 삼고 StrictMode confirm Promise 결과를 유지한다.

#228은 Repository baseline YES/Product Complete NO를 명시했다. 실제 Test Browser requestPayment→success/fail→confirm→reload와 인증 전체 여정은 보류됐다. Live/Production/Secret/실결제 승인은 포함하지 않으며 후속 QA 근거로 유효 범위를 갱신한다.

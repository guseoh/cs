# UX 補助 Skill と Draft レビューは既存設計権威を保ったまま導入する

UI/UXProMaxのpinnedupstreamを補助として導入し、ユーザー決定/PawCycleDesignContractと既存ux-designerを上位に保つ。runtime製品やdependencyは変更しない。whitespace正規化/探索実行を報告したがPyYAML不足のquickvalidator・既存sessionでの即時検出は未確認だった。

Draft自動CodeRabbitはdrafts一行のみ有効化し使用量増の代価を認めた。設定の保存と実レビュー実施は別であり、現在調査からreview依頼は行わない。大規模vendoreddataのpatch省略は原文取得と限定した構造検査として明示する。

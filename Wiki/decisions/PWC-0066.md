# 장애 후보 감지와 알림 전달의 검증 단계를 분리한다

local Prometheus는 Backend up==0 for30초와 reconciliation 증가30초를 후보 신호로 삼는다. 원인 판정은 incident Runbook이 담당한다. disposable에서 pending/firing/resolved를 관측한 뒤 별도 승인으로 Alertmanager→Discord 전달을 추가했다.

webhook은 untracked runtime file로만 주입한다. 전역 notification counter를 alert별 수신 증거로 쓰는 대안은 배제했다. 최종 #120은 자동 wrapper 대신 두 장애 firing/resolved의 Local Manual Verified와 static config 검증을 남긴다.

이력은 local 감지→수동 수신→후속 AWS 양 채널 전달(PWC-0018)로 연결한다. Production 임계값·escalation·상시 자동 스케줄은 local 성공으로 승인하지 않는다.

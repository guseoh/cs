# 분야를 넘나드는 교양 읽기 — 운영 현황

## 현재 상태 (2026-11-21)

**목적은 시험·전공 학습이나 기록 축적이 아니라, 한국어 글과 책을 즐기며 세상을 이해하는 시야를 넓히고 여러 관점에 대해 스스로 생각하는 것이다.** 사용자 확정에 따라 여러 분야를 넘나드는 자유로운 읽기를 채택했다. 첫 정식 교양 아티클의 발행·완독이나 정기 발행 설정이 완료된 것은 아니다.

## 확정된 결정

- [교양 아티클 작성·자료 연결 방식 GRD-0001](../decisions/GRD-0001.md)을 운영 기준으로 사용한다.
- AI는 호기심을 자극하는 질문을 골라 **한국어 교양 칼럼**을 작성한다. 주제별로 철학·심리·사회·정치·경제·역사·과학 등의 관점을 자연스럽게 연결하되, 정해진 과목 순서를 강제하지 않는다.
- AI는 해당 주제와 직접 관계된 **개인 블로그(네이버·티스토리 등), 전문가 칼럼, 공식·연구기관의 한국어 자료, 관련 도서**를 링크와 함께 제시하고, 읽어볼 이유와 관점의 차이를 설명한다.
- 사용자는 아티클과 책을 자유롭게 읽고 **스스로 별도 정리·사색**한다. AI는 읽기 완료 기준, 독후감, 정리 템플릿, 강제 퀴즈·진도를 요구하지 않는다.
- [읽을거리 후보 목록 GRK-0001](../knowledge/GRK-0001.md)은 검색의 출발점이며 실제 각 아티클에 사용할 자료는 주제별로 새로 검증한다.

## 관심 범위와 제외

- **포함:** 인문·삶, 철학, 심리학, 사회학, 정치와 국가, 국제관계와 세계정세, 경제학, 역사, 과학. 인접 분야를 가로지르는 글도 허용한다.
- **당분간 제외:** 예술·미학 중심의 주제. 사용자가 관심을 바꾸면 범위를 조정한다.
- **자료 성격:** 책과 함께 읽는 한국어 아티클, 일반 개인 블로그의 경험·주장, 공신력 있는 출처의 근거와 반론. 책은 의무 독서 목록이 아니라 관심이 생긴 주제의 선택지다.

## 제약 조건

1. 공개 Wiki에 비공개 대화 원문, 개인적 메모와 독후감 또는 식별 가능한 사적 기록을 게시하지 않는다. 이 문서는 공개 가능한 운영 원칙만 요약한다.
2. 개인 에세이·정치적 의견·전문가 분석·연구 결과를 각각 구분한다. 논쟁적인 주제는 상반된 견해와 근거를 공정하게 소개하고 특정 진영의 선택을 유도하지 않는다.
3. 외부 링크, 저자·출처, 자료 접근 가능 여부, 출판 정보는 **매회 추천 전에 실제로 확인**한다. 기존 대화의 추천만으로 출처의 정확성이나 현재 운영 상태를 보증하지 않는다.
4. 정기 자동 발행, 외부 사이트 게시, 개인 독서 기록 자동 수집 및 Wiki 자동 기록은 결정하거나 설정하지 않았다. 새 기능은 별도 사용자 요청과 검증이 필요하다.

## 미해결 질문과 다음 작업

- 사용자가 처음 읽을 주제 또는 제시된 후보 중 원하는 질문으로 **첫 정식 아티클**을 시작한다. 구체적인 발행 주기, 플랫폼, 길이 제한은 강제하지 않는다.
- 외부 아티클과 도서는 매 주제별 새 검색을 통해 선별한다. 별도의 책 구매나 유료 구독을 기본으로 가정하지 않는다.

## 근거와 검증 범위

2026-11-21까지의 사용자 확정 방향을 비공개 대화 원문 없이 공공에 게시 가능한 범위로 요약했다(`sources: []`, `evidence_level: user-confirmed`). 실제 아티클 출판, 읽기 완료, 외부 링크 전체 검증, 주기적 전달 및 성과 측정은 아직 수행되지 않았다.

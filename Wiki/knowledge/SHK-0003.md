# Hermit 에이전트 IDE 심층 코드 분석 및 개선·확장 마스터 플랜 (2026-11-27)

## 요약

[guseoh/hermit](https://github.com/guseoh/hermit)(커밋 `dc07cb3`, 배포 기준 v0.1.7)의 전체 소스를 정독해 아키텍처·설계·기능·디자인·UI/UX 마찰 지점을 전수 진단하고, **Orca · T3 Code · Conductor · Codex App · Claude Code Desktop · Google Antigravity (2.0 / IDE / `agy`)**의 검증된 패턴을 Hermit의 정체성(Windows PowerShell 5.1 · 초경량 Electron · 로컬 BYOS CLI)에 맞게 선별 반영한 종합 개선 청사진을 정리했다. 원본 상세 설계 문서는 [docs/design/hermit-master-plan.md](https://github.com/guseoh/hermit/blob/b12629b/docs/design/hermit-master-plan.md)(`b12629b`)에 반영되었으며, 본 문서는 후속 세션이 대화 원문 없이도 현재 결함·벤치마크 판정·UX 개선 방향·점진적 모듈화 전략을 복원할 수 있도록 핵심 근거와 계획을 기록한다.

> 본 기록의 코드 결함·아키텍처 진단은 `dc07cb3` 소스 정독으로 확인된 사실이며, Stage A~D 개선안과 신규 기능 제안은 **미구현·제안 상태**다.

## 1. 아키텍처 및 코드 진단

### 핵심 강점 (소스 확인)
- **에이전트 런타임 멀티플렉싱:** `codex-host.cjs`가 앱 전체에서 `codex app-server --stdio` 프로세스 1개를 공유하고 `threadId`로 작업을 라우팅하며, `agent.cjs`의 `nativeCodex()`가 npm 래퍼 대신 네이티브 `codex.exe`를 숨김 실행한다. worktree 삭제·TUI 전환 전 `releaseFolder()`가 유휴 시 서버 재시작, 타 작업 실행 중 시 `thread/loaded/list` 폴링으로 Windows 폴더 잠금을 해제한다.
- **Claude 지속 세션 및 TUI 훅:** `claude.cjs`는 `--input-format stream-json` stdin을 유지(유휴 15분 후 종료, 다음 턴 `--resume`)해 턴당 시작 지연(2~5초)을 제거하고, `agent-hooks.cjs`는 작업 저장소를 건드리지 않고 24바이트 랜덤 토큰(`timingSafeEqual`)으로 보호된 Windows Named Pipe로 Claude hooks 및 Codex `notify` 상태를 수신한다.
- **비파괴 체크포인트 및 PowerShell 통합:** `checkpoints.cjs`는 사용자 인덱스를 복사한 임시 `GIT_INDEX_FILE`로 턴 스냅샷(`refs/workbench/checkpoints/...`)을 생성·복원하며, `prompt.ps1`은 UTF-8 출력 인코딩을 고정하고 OSC 777 마커로 명령어·성공 여부·소요 시간·디렉터리를 구조화한다.
- **보안 경계:** `sandbox: true`, `contextBridge`, `trusted(event)`(sender + mainFrame 검증), 엄격한 CSP, `execFile`/`spawn` 인자 배열 실행, `fs.realpath` 경로 탈출 차단을 유지한다.

## 3. UI/UX 10대 불편 지점과 개선 설계

1. **UX-1 새 작업 4단계 모달 마찰:** 홈/`Ctrl+N` 즉시 입력 시작 + 프로젝트 행 `+`를 새 작업 시작 기본 동작으로 전환.
2. **UX-2 터미널 3중 분산 & 버튼 3곳 중복:** 우측 커밋 버튼을 가리던 우하단 `#quick-tools-trigger` 및 미사용 `#quick-tools` 제거, 작업 하단/탭 터미널과 `Ctrl+Alt+A` 플로팅의 역할 분리, TUI 강제 최대화 해킹 정리.
3. **UX-3 분할 채팅 헤더 누락:** `primaryChatPanel` 전역 ID 의존(`renderTaskHeader`)을 제거하고 `createDockedChat()` 내부에 패널별 작업 컨텍스트 바(브랜치·PR·비교·`[채팅|터미널]`) 내장.
4. **UX-4 채팅 작성·읽기 피로:** 입력창 자동 높이 확장, Ctrl+V 이미지 첨부, 확장 `@` 멘션, 라이브 체크리스트 바, 코드 블록 복사/구문 강조, 연속 읽기 도구 그룹 접기, 메시지 복사/분기.
5. **UX-5 승인 클릭 피로 & 네이티브 `confirm()`:** 키보드 승인(`Y`/`A`/`N`) + Allowlist/Denylist + `confirm()` 3곳을 공용 다크 `<dialog>`로 교체.
6. **UX-6 Diff 검토 제약:** Shift 범위 선택 + 인라인 플로팅 액션, 다중 Diff 탭, 스테이지 버튼 상시 옅은 표시.
7. **UX-7 파일 탐색 부재 & `<textarea>` 모달:** 우측 파일 트리/`rg` 검색 탭 + 소스/에러 `파일:행`을 메인 WorkArea 탭으로 열기.
8. **UX-8 좁은 사이드바 칸반:** 350px 우측 패널의 5열 가로 스크롤 칸반을 **메인 캔버스 전체 폭 탭**으로 승격.
9. **UX-9 키보드 탐색 부족:** `Ctrl+N`, `Ctrl+P`, `Ctrl+Shift+F`, `Ctrl+Tab`, `Ctrl+1~9`, `Alt+Left/Right`, `Ctrl+W` 보강.
10. **UX-10 탭·작업 관리 혼란:** 탭 우클릭 메뉴, Pin/Archive/Tag 필터, 병합된 worktree 일괄 정리.

## 4. 점진적 모듈화 및 3대 에이전트(`agy` 포함) 확장 전략

- **점진적 ES 모듈 분리 (Zero-Bundler):** 기존 전역 스크립트를 전면 재작성하지 않고 `window.hermit` 브리지(`renderer/core/store.mjs`, `renderer/ui/dialogs.mjs`)를 두고 수정·신규 도메인(`markdown.mjs`, `approval.mjs`, `kanban.mjs`, `files.mjs`, `code-tab.mjs`, `pipeline.mjs`, `settings.mjs`)부터 `<script type="module">`로 분리한다. CSP `script-src 'self'` 유지 및 `node --test` 직접 단위 테스트가 가능하다.
- **3대 에이전트 프로바이더(`AgentAdapter`):** 현재 코드의 `claude`/`codex` 이진 분기를 공통 어댑터 레지스트리로 정리하고, **Google Antigravity (`agy`)**를 ① 1단계 `agent-probe.ps1`/`prompt.ps1` TUI 런처 + `.agents/` 설정 허브 연동 → ② 2단계 `main/adapters/antigravity.cjs`(스트리밍 CLI 또는 로컬 `ConversationService` Connect HTTP+JSON / Python SDK 브리지) 채팅·3자 비교·이어받기 통합 순으로 확장한다.

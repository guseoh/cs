# Spring Framework / Spring Boot — 7과정·34개 학습 단위 제안

## 상태와 근거 구분

**상태: 제안(draft), 사용자에게 상세 커리큘럼 최종 승인받지 않음.** 2026-11-08 ChatGPT 대화에서 작성한 7과정·34개 주제·17개 최우선 심화 주제를 향후 검토·재사용할 수 있도록 정리했다. [BLR-0009](../decisions/BLR-0009.md)에 기록된 **확정된 학습 방법**과 이 문서의 **아직 검토 중인 주제별 커리큘럼**을 구분한다.

제안의 기초는 사용자가 별도로 제공한 Spring 강의 PDF와 예제 코드다. 이전 분석은 두 압축파일에서 **PDF 87개, 총 2,206쪽**을 확인했다고 보고했으며, 첫 묶음 72개와 고급편 15개가 포함된 것으로 설명했다. **이 Wiki 기록 작업은 원본 전체 본문 및 개별 코드의 최신 버전 실행을 다시 검증한 작업이 아니며**, 공개 URL이 없는 비공개 제공 파일과 대화 원문은 저장하지 않는다. 따라서 자료 매핑·추가 주제·우선순위는 후속 검토 가능한 설계 제안으로 취급한다.

## 학습 목적과 범위 — 확정된 원칙

- 목표는 **현대적인 Java/Spring Boot REST API 백엔드 구현·설계·운영에 필요한 Spring Framework와 Spring Boot의 핵심 원리**를 이해하는 것. 김영한 로드맵의 선택된 7개 과정은 *전체 흐름*을 위한 참고 기준이며, 강의 차시와 설명 글을 1:1로 대응하지 않는다.
- PDF는 개념 순서·예제 코드·그림을 위한 참고 자료다. Spring의 현재 API·행동·버전 차이는 공식 문서 및 신뢰할 수 있는 자료로 확인하고, PDF 근거와 외부 보완을 구분한다.
- 핵심 개념은 Java 객체 생성·참조, Bean 구성·실행 흐름, 프록시·트랜잭션 자원, 예외 및 실무 영향까지 충분히 설명한다. 부차적 기능은 목적·구성·사용·주의사항 중심으로 **유연하게** 다룬다.
- 학습할 필요가 낮은 강의 단원은 별도의 요약문을 만들지 않고 제외한다. 초기 MVC의 Servlet/JSP/수제 Front Controller 발전 과정은 Spring MVC가 등장한 배경을 이해할 최소 범위로 남긴다.
- 학습 글은 완결된 **Spring 개념 설명**으로 구성한다. 국내 IT 기업·Tecoble 등 한글 기술 자료, 공식 문서, 실제 그림·간결한 UI 도식을 설명 근처에 제공한다. 별도 퀴즈·이해 확인·실습/테스트 과제를 기본 단계로 요구하지 않는다. 필요한 코드는 제공 PDF 예제를 우선 활용한다.
- 별도 Java·JPA·DB·HTTP·Spring Security 과정의 상세 학습을 반복하지 않는다.

## 확인할 사항과 후속 결정

1. 87개 PDF의 **개별 본문/목차 근거**와 제안된 34개 주제의 매핑을 최종 대조한다. 파일 수·페이지 수만으로 내용 검증이나 코드 실행이 완료되었다고 주장하지 않는다.
2. 전체 구성의 34개 단위가 필요한 만큼 충분한지, 17개 최우선 심화의 우선순위가 실제 코드 작성·문제 해결에 부합하는지 승인받는다.
3. Spring Boot 기준 버전, PDF의 구버전 예제, 새로 보완한 공식 API를 구분한다.
4. 승인 전까지 본 문서는 **제안**이며 [BLR-0009](../decisions/BLR-0009.md)의 확정된 학습 방식만 유지한다.

## 출처와 한계

사적 강의 PDF와 ChatGPT 커리큘럼 제안을 공개 저장소에 옮기지 않고, 학습 토픽·편집 결정·남은 검증 항목만 정리했다. 공개 검증 링크가 없으므로 `sources: []`이고 `evidence_level: unverified`로 표시한다. 사용자 확인 후에도 실제 PDF 매핑과 실행 검증은 별도 주장이어야 한다.

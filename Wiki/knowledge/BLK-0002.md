# Spring Framework / Spring Boot — 7과정·34개 학습 단위 확정 커리큘럼

## 상태와 근거 구분

**상태: 확정(published), 2026-11-08 사용자 승인.** 이 문서는 Spring Framework/Spring Boot **7과정·34개 학습 주제·17개 최우선 심화 주제**로 구성된 학습 커리큘럼이다. 학습 방식은 [BLR-0009](../decisions/BLR-0009.md), 구체 로드맵의 확정 결정은 [BLR-0010](../decisions/BLR-0010.md)에 기록한다. 주제의 구성·깊이·제외 범위를 채택했다는 의미이며, 실제 학습이나 PDF의 각 코드 실행을 완료했다는 뜻은 아니다.

제안의 기초는 사용자가 별도로 제공한 Spring 강의 PDF와 예제 코드다. 이전 분석은 두 압축파일에서 **PDF 87개, 총 2,206쪽**을 확인했다고 보고했으며, 첫 묶음 72개와 고급편 15개가 포함된 것으로 설명했다. **이 Wiki 기록 작업은 원본 전체 본문 및 개별 코드의 최신 버전 실행을 다시 검증한 작업이 아니며**, 공개 URL이 없는 비공개 제공 파일과 대화 원문은 저장하지 않는다. 따라서 **학습 범위와 우선순위는 사용자 확정 사항**이나, 원본 PDF의 개별 매핑과 Spring 버전별 API 세부 사실은 각 주제에서 별도로 검증해야 한다.

## 학습 목적과 범위 — 확정된 원칙

- 목표는 **현대적인 Java/Spring Boot REST API 백엔드 구현·설계·운영에 필요한 Spring Framework와 Spring Boot의 핵심 원리**를 이해하는 것. 김영한 로드맵의 선택된 7개 과정은 *전체 흐름*을 위한 참고 기준이며, 강의 차시와 설명 글을 1:1로 대응하지 않는다.
- PDF는 개념 순서·예제 코드·그림을 위한 참고 자료다. Spring의 현재 API·행동·버전 차이는 공식 문서 및 신뢰할 수 있는 자료로 확인하고, PDF 근거와 외부 보완을 구분한다.
- 핵심 개념은 Java 객체 생성·참조, Bean 구성·실행 흐름, 프록시·트랜잭션 자원, 예외 및 실무 영향까지 충분히 설명한다. 부차적 기능은 목적·구성·사용·주의사항 중심으로 **유연하게** 다룬다.
- 학습할 필요가 낮은 강의 단원은 별도의 요약문을 만들지 않고 제외한다. 초기 MVC의 Servlet/JSP/수제 Front Controller 발전 과정은 Spring MVC가 등장한 배경을 이해할 최소 범위로 남긴다.
- 학습 글은 완결된 **Spring 개념 설명**으로 구성한다. 국내 IT 기업·Tecoble 등 한글 기술 자료, 공식 문서, 실제 그림·간결한 UI 도식을 설명 근처에 제공한다. 별도 퀴즈·이해 확인·실습/테스트 과제를 기본 단계로 요구하지 않는다. 필요한 코드는 제공 PDF 예제를 우선 활용한다.
- 별도 Java·JPA·DB·HTTP·Spring Security 과정의 상세 학습을 반복하지 않는다.

## 학습 시작과 이후 검증

1. **새 채팅에서 01번부터 시작한다.** 이전 대화에서 작성된 설명글은 진도 완료로 표시하지 않는다. 첫 글은 객체지향 설계·IoC·DI를 Spring 학습 중심으로 통합 설명한다.
2. 01~34의 순서와 심화/표준 배분을 기본으로 유지한다. 제공 PDF의 예제·그림은 이해 보조 자료로 사용하며, 사용자 요청 없이 별도 퀴즈·실습·테스트 과제를 제공하지 않는다.
3. 개별 주제를 작성할 때 해당 PDF 본문·예제와 최신 Spring 공식 문서를 확인한다. PDF가 지원하는 설명과 최신 기술로 보충한 내용을 구분한다.
4. 별도 JPA·DB·HTTP·Spring Security 학습과 중복되는 상세 구현을 반복하지 않는다. 사용자가 이후 학습 범위를 바꾸기로 결정한다면 별도 변경 이력을 기록한다.

## 출처와 한계

사적 강의 PDF와 ChatGPT 커리큘럼 제안을 공개 저장소에 옮기지 않고, 학습 토픽·편집 결정·남은 검증 항목만 정리했다. 공개 검증 링크가 없어 `sources: []`이며 `evidence_level: user-confirmed`는 **커리큘럼 선택에 대한 사용자 승인**만 의미한다. 실제 PDF 매핑, 최신 API의 정확성 및 코드 실행 검증은 별도 주장이어야 한다.

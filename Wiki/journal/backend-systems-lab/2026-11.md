# 백엔드 시스템 설계·구현 연구실 진행 기록 — 2026년 11월

## 2026-11-19 — 여섯 도메인 독립 앱과 교재 1·2권의 단일 저장소 운영 확정

- **사용자 확정:** 하나의 GitHub 저장소에 물류·대중교통 경로 검색·부동산 실거래가 분석·티켓팅·주차장·이벤트 분석의 **서로 독립적으로 실행되는 여섯 Spring Boot 학습 애플리케이션**을 모듈별로 관리한다.
- **사용자 확정:** 『가상 면접 사례로 배우는 대규모 시스템 설계 기초』 **1권과 2권**도 **같은 저장소에서 설계 실습**한다. 각 장을 별도 서버로 강제하지 않으며 별도 학습 트랙으로 기록한다.
- **사용자 확정:** 도메인별 학습 목표를 차별화한다. 우선 물류를 시작할 기존 방향은 유지하되, 각 도메인의 상세 기능 범위와 교재별 실행 실험은 아직 정하지 않았다.
- **기존 결정 유지:** AI가 채팅에 정답 코드/명령을 주면 사용자가 빠르게 로컬에서 작성·실행하고, 핵심·고급 기술은 설명과 단계별 힌트로 시작한다. 최종 설계 선택은 사용자.
- **설계 제안:** Monorepo + Gradle 멀티 프로젝트, 각 앱의 DB·API·테스트 격리, `design-studies/volume-1`·`volume-2` 문서 및 선택적 `experiments/` 코드. 폴더명과 구체 도구 버전은 미확정.
- **아직 없음:** 신규 GitHub 저장소·GitHub Wiki·Gradle 빌드·코드·CI·실제 성능 실험·교재 장별 완료 기록.
- **다음 작업:** 루트 저장소 구조/개발 환경을 사용자와 결정하고, 초기 물류 기능 요구사항 및 교재 첫 설계 주제를 선정한다.

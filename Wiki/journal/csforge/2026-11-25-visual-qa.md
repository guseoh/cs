## 검증 결과

- Reader 자동 검사 PASS. Vite 빌드와 Chromium에서 실제 Reader 경로를 열고, canonical 본문을 합성 API로 제공했습니다. 396개 시각 콘텐츠 Concept의 Guest 1,584조건과 15개 영역 대표 Owner 60조건 모두 오류 0건입니다. 각 조건은 수동 라이트·다크, 900px·1280px 데스크톱 크기를 사용했습니다. 단계형 조작부 39개에서 키보드로 다음 단계 116회를 진행했고 이전·초기화가 있는 경우 확인했습니다. 이미지 확대·ESC·포커스 복귀를 대표 화면에서 확인했습니다.
- 시각 검사 PASS 범위. 활성 SVG 265개를 Chromium에서 직접 열어 글자 경계가 viewBox 밖으로 잘리는 항목 0건을 확인했습니다. 80개 Reader 스크린샷을 수집했고 대표 도식은 확대와 라이트·다크를 육안 확인했습니다. DSA 피보나치 도식의 1280px 표시 너비는 322px에서 644px로 늘었습니다. 전체 픽셀 겹침 및 모든 도식 의미의 육안 검수는 남았습니다.
- 실제 연결 검사 PASS. 별도 로컬 PostgreSQL 16.4와 Spring에 프런트엔드를 연결해 정본 3,410개 생성 후, DSA 표·Java Heap·Network TCP 핸드셰이크·PostgreSQL Read Committed 도식을 Reader에서 열어 8조건을 확인했습니다. Heap offer/poll 후 불변식과 TCP 단계별 접근성 제목을 직접 조작했습니다. 같은 HTTP 진입점으로 3,410개 모두 UNCHANGED를 확인했고, 기존 Concept ID와 합성 진도·북마크·노트가 보존됐습니다.

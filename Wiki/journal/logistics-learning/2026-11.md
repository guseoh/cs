# 물류 시스템 학습 진행 기록 — 2026년 11월

## 2026-11-19 — 물류 학습 프로젝트 착수 및 협업 방식 확정

- **확정:** 신규 대규모 프로젝트의 도메인은 물류, 목적은 Java/Spring 기반 학습·이해·실험이다. 포트폴리오 전환은 후속 검토한다.
- **확정:** 현재 ChatGPT 채팅에서 요구사항, 도메인, 로직, 트랜잭션·동시성, 성능 및 기술 선택을 공동 논의하고, 일반 구현의 완성 코드는 AI가 채팅에 제시하면 사용자가 빠르게 로컬에서 작성·실행한다.
- **확정:** Kafka, 장애 복구, 데이터 파이프라인, 캐싱 및 고급 최적화는 개념·힌트·첫 시도·피드백을 기본으로 하되 사용자가 정답 코드를 요청하면 제공한다.
- **확정:** 주요 설계·결정·실험·실패·진행 경위를 프로젝트 Wiki(생성 후)와 중앙 `guseoh/cs/Wiki`에 모두 반영한다. 현재는 **중앙 Wiki만 실재**한다.
- **제안:** 첫 학습 범위를 출고센터 선택·재고 할당으로 좁히고, 이후 동시성·검색 성능·이벤트·복구를 실제 문제에 따라 학습한다.
- **미완료:** 신규 소스 저장소/프로젝트 GitHub Wiki 생성, 확정 요구사항, 코드 작성, 테스트, 성능 측정, 배포.
- **다음 작업:** 물류 하위 도메인과 첫 사용 시나리오·요구사항 확정 → 도메인/DB/API 설계 초안.
- **관련 결정:** [LGR-0001](../../decisions/LGR-0001.md), [BLR-0014](../../decisions/BLR-0014.md), [학습 설계 초안](../../knowledge/LGK-0001.md).

## 2026-11-19 — 물류는 통합 학습 저장소 안의 첫 독립 앱으로 위치 확정

- [BLR-0015](../../decisions/BLR-0015.md): 신규 학습 저장소에 여섯 도메인을 각각 독립 실행 Spring Boot 앱으로 두는 방식이 사용자 확정되었다. 물류는 그중 `logistics` 앱이며 기존의 물류 고유 요구사항·설계·실험 기록은 유지한다.
- [BLR-0016](../../decisions/BLR-0016.md): 시스템 설계 교재 1·2권도 동일 저장소의 별도 설계 트랙으로 합류한다. 물류 코드와 억지로 결합하지 않는다.
- 통합 공통 이력은 [통합 프로젝트 Journal](../backend-systems-lab/2026-11.md)을 확인한다. 개별 API/DB, 새 GitHub 저장소/Wiki, 구현/테스트는 아직 없다.

# MySQL 초기화 환경 변수를 바꿔도 기존 named volume의 계정은 바뀌지 않는다

## Failure / evidence
#90서버ready인데healthcheck/직접TCP1045가발생했다. 기존7월14일volume에저장된계정과새env가달랐다. 초기화env는빈datadir에만적용되므로프로세스재시작/새env만으로기존계정을바꾸지않는다.

# 파일을 되돌려도 exact SHA 실행 승인은 자동 복원되지 않는다

## Context
#320은 I10K를25→50→100→150 순서로 실행하고 실패 시 중단하는 제한 승인을 받았다. 이후 잘못된 GitHub 쓰기로 main에 빈 파일을 만들었다가 다음 commit에서 삭제했다. 순수 파일 차이는0이었지만 main 이력과 SHA는 변했다.

## Lesson
내용 동등성과 승인된 실행 대상의 동일성은 다르다. exact SHA를 고정한 실행에서는 변경 전 승인·환경 확인을 새 SHA에 자동 승계하지 않는다. 당시 DB·dataset·runtime·tunnel·k6 실행을 중단하고 양쪽 소스 재확인과 읽기 전용 Gate 재검증을 요구했다. 이력 강제 재작성으로 사고 흔적을 지우지 않는다.

## Limits
이는 당시 공개 사고 보고와 중단 경계의 기록이다. 제품 실행·복구를 이번 Wiki 작업에서 재실행하지 않았다. 기존 I10K 비교 보류와 후속 별도 측정 결과를 같은 실행 성공으로 합치지 않는다.

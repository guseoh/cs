# 실행 runner를 막아도 함께 로드되는 profile의 쿠키 완화는 남을 수 있다

## Failure / correction
#44 local-integration,production 조합은 bootstrap runner를 차단했지만 profile property의 Secure=false는 계속로드됐다. 따라서 기능비실행과 설정비적용은 동치가 아니다. cookie완화를 local profile에서 제거하고 local HTTP용 SRE process환경에만 한정했다.

## Verification / applicability
prod별칭·test·production혼합의 비실행과fixture충돌/rollback을 검증했다. 기존row잠금을 빈DB동시최초생성보장으로 과장한 문구도 단일인스턴스/최초생성미직렬화로 교정했다. 원격Java25/MySQL 성공은 당시로컬toolchain부재를 지우지 않는다. [상세](../history/pawcycle-source-ledger/batch-041-050.md).

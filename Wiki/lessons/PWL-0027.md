# 환경 baseline 실패와 코드 회귀를 분리하고 DDL rollback 호환을 검증한다

retention 작업의 process timeout2건은 동일 immutable baseline에서도 재현됐다. 성공 집중 테스트·143개 통과와 DB reset 인증 실패로 무효인 전체 실행을 별도 기록한다. 실패를 숨기거나 환경 오류를 구현 회귀로 단정하지 않는다.

MySQL DDL은 transaction rollback을 기대할 수 없어 단일 DDL별 version으로 분리했다. 구버전으로 rollback한 동안 생긴 completed_at null 성공 row는 bounded repair 후 새 grace를 주며 incomplete reservation은 보존한다. replay와 cleanup은 독립 transaction/latch로 선점 순서를 검증한다.

Java25/MySQL8.4 격리 테스트는 Production DDL·cleanup·복구 검증을 대신하지 않는다.

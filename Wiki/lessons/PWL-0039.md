# 읽기 전용 archive 권한은 실제 container user의 traverse·read로 검증한다

#291의 opc 소유 immutable archive는 #292에서 directory0500/file0400 때문에 Prometheus nobody가 template를 읽지 못해 Permission denied/restart loop를 만들었다. source directory0555/file0444와 non-owner positive/negative read·traverse 및 post-start restart 회귀로 교정했다. root나 소유자가 읽을 수 있다는 사실을 실제 container user의 접근 근거로 삼지 않는다.

관측과 metrics-proxy만 rollback하고 Application3서비스 healthy를 보존했다. 저장소 교정·회귀 검증과 실제 OCI 재적용은 별개다. 이어진 #293 network/localhost 문제는 기존 [PWL-0001](PWL-0001.md)로 통합하며 별도 중복 교훈을 만들지 않는다.

# 기술 자료

국내 기업의 실무 기술 글을 모으는 읽기 목록이다. 자동 수집 자료와 직접 학습한 개념 노트를 분리해 관리한다.

> [!info] 읽기 흐름
> **inbox**(읽기 대기) → **reading**(읽는 중) → **reviewed**(학습 완료). 더 이상 읽지 않을 글은 **archived**로 이동한다. 새 자료는 항상 inbox로 수집되며, 읽기 상태는 직접 변경한다.

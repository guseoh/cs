# ODW #7: 세 가지 방법으로 토큰 소비량 40% 절감! ADK를 이용한 컨텍스트 엔지니어링

> [!abstract] 한 줄 정리
> AI 컨텍스트도 CPU·메모리처럼 유한한 자원이므로 현재 작업에 필요한 도구와 정보만 전달하는 구조가 중요합니다.

> techblog.lycorp.co.jp

## 핵심 내용

Claude Code·Cline·ADK 사용이 늘며 토큰 비용, 긴 대화 정확도 저하, 불필요한 도구 정의로 컨텍스트가 커지는 문제를 다룹니다. 필요한 MCP 도구만 노출하는 `tool_filter`, 작업별 에이전트 분리, 입출력 스키마 구조화를 Jira 보고서 생성 에이전트에 적용했습니다. 개선 버전은 평균 컨텍스트 윈도 사용률을 26.03%p 낮추고 총 토큰 사용량을 40.7% 줄였습니다.

토큰 사용량을 줄이는 작업은 모델에게 말을 짧게 하라고 지시하는 것이 아니라 **작업에 필요하지 않은 도구 정의와 이전 실행 이력을 제거하는 작업**이다. 같은 에이전트가 모든 MCP 도구를 알게 하면 정작 필요한 계약을 찾는 데 시간이 늘고 잘못된 호출을 선택할 가능성도 커진다. `tool_filter`로 도구 표면을 좁히고 역할별 에이전트를 나누며 입력·출력을 스키마로 고정하면 실행 경로를 더 쉽게 검증할 수 있다.

| 개선 수단 | 줄이려는 비용 |
| --- | --- |
| 필요한 MCP 도구만 노출 | 도구 설명 토큰·선택 오류 |
| 역할별 에이전트 분리 | 관련 없는 대화 이력 |
| 입출력 구조화 | 장황한 중간 결과·파싱 오류 |

원문의 **총 토큰 40.7% 절감, 컨텍스트 사용률 26.03%p 감소**는 해당 Jira 보고서 실험의 측정치이며 다른 업무에 자동 보장되는 절감률은 아니다.

## 왜 읽을까

AI 코딩을 좋은 프롬프트 문제가 아니라 컨텍스트와 도구, 책임을 설계하는 시스템 문제로 볼 수 있습니다.

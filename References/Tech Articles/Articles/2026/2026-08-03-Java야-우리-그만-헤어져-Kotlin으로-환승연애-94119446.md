# Java야…, 우리 그만 헤어져. Kotlin으로 환승연애

> [!abstract] 한 줄 정리
> 큰 전환일수록 테스트로 기존 동작을 고정하고 작은 배포 단위로 나누면 운영 위험을 크게 줄일 수 있습니다.

> techblog.woowahan.com

## 핵심 내용

2018년부터 운영한 Java 기반 포인트 시스템을 약 3개월에 걸쳐 Kotlin으로 전환한 기록입니다. 테스트 코드를 먼저 옮기고 운영 코드는 기능·패키지 단위로 나눠 총 10번 점진 배포했으며, 82개 작업 티켓을 처리하는 동안 전환으로 인한 운영 장애가 없었다고 설명합니다. null 처리, Lombok 제거, QueryDSL DTO 매핑, Jackson 역직렬화, Spring 트랜잭션 예외 차이까지 검토했고 코드 스멜은 330개에서 4개, 테스트 커버리지는 61.5%에서 76.7%로 개선됐습니다.

## 왜 읽을까

언어 전환 성공담보다 운영 중인 시스템을 어떻게 안전하게 바꾸는지가 중심입니다. 일반적인 리팩터링이나 대규모 구조 변경에도 적용할 수 있는 방식입니다.

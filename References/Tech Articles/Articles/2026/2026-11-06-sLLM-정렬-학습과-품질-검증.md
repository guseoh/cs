# 측정할 수 없으면 개선할 수 없다 - AI Pick 추천 카드를 위한 sLLM 정렬 학습기

> [!abstract] 한 줄 정리
> LLM 생성 결과가 JSON과 글자 수 규칙을 지키는 것과 실제 상품에 맞는 자연스러운 문구를 만드는 것은 서로 다른 품질 축이다. 올리브영은 형식은 결정적 검증기로 걸러내고, 자연스러움·문맥적합은 별도 언어모델의 NLL을 지표로 삼아 DPO 선호 학습 후 발생한 형식 저하를 과제별로 다르게 보정했다.

상품 설명 이미지는 OCR과 특징 추출을 거쳐 구조화되며, 카드 생성 모델이 `reason`·`title`·`subtitle`를 만든다. 이미지에서 보여준 전체 과정 중 학습의 초점은 **카드 생성 단계의 형식 제약과 문구 품질을 동시에 개선하는 방법**이다.

## 핵심 내용

### 생성 파이프라인과 품질 조건

AI Pick은 상품 상세 내용을 OCR과 특징 추출 모델로 구조화한 뒤, Gemma3-4B-it 기반 소형 언어모델(sLLM)로 개인화 WHO 카드 또는 상황 중심 TPO 카드의 `reason`·`title`·`subtitle` 문구를 만든다. 결과는 지정된 JSON 스키마와 글자 수·어미 규칙을 지켜야 하며, 상품에 없는 효능이나 성분을 덧붙여도 안 된다. 그런데 출력 형식에만 맞춘 SFT(Supervised Fine-Tuning)는 읽기 어색하거나 상품 맥락을 잘못 이해한 문구까지 허용했다. 초기 형식 중심 평가에서 SFT 모델은 WHO 81.1%, TPO 78.5%를 통과했지만, 이는 후속 정렬 실험의 평가 기준과 데이터셋이 달라 직접 비교해서는 안 된다.

### 형식 검증과 언어 품질 지표 분리

팀은 평가를 두 부분으로 분리했다. JSON 구조, 필드 길이, 어미, 슬롯 허용값 같은 **형식은 규칙·정규식으로 단정적으로 판정**하고, 자연스러움과 문맥적합은 독립된 공개 한국어 모델 Polyglot-Ko-1.3B의 NLL(Negative Log-Likelihood)로 근사했다. `nll_nat`은 문장 자체의 자연스러움, `nll_ctx`는 주어진 상품 정보와 출력의 연결을 나타내며 **값이 낮을수록 더 좋다**. 사람 평가는 기준 통일에 비용이 들고 LLM-as-a-judge 역시 지침·응답 순서에 따라 흔들리므로, 지표를 학습 신호로 사용할 수 있도록 설계한 것이다. 다만 NLL은 실제 사용자 만족도의 정답이 아니라 프록시 지표다.

![형식 NLL 검사와 선호 학습 DPO GRPO 과정](https://oliveyoung.tech/_img/f6c910050ad220ec-1024.webp)

이 그림에서 중요한 경계는 형식을 통과하는 출력과 그중 품질이 좋은 출력을 구분한다는 것이다. 정규식·스키마 검증과 NLL 지표를 별도로 유지한 뒤 선호 데이터에 반영했다.

### WHO: formatmix로 형식 통과율 회복

DPO(Direct Preference Optimization)는 선호·비선호 출력 쌍을 학습해 자연스러움과 문맥적합 지표를 개선했지만, 형식 준수율을 떨어뜨렸다. WHO 카드의 홀드아웃 평가에서 형식 통과율은 SFT 86.7% → DPO 62.8%가 됐다. 이를 보정하려고 필드 길이 등을 근소하게 어긴 near-miss 출력을 비선호 예제로 혼합하는 `formatmix`를 적용했다. 채택한 혼합 비율 0.25에서 형식 통과율은 **76.0%로 13.2%p 회복**했고, 자연스러움 NLL 중앙값 3.096을 DPO와 동일하게 유지했다. 비율 0.50에서는 형식이 더 회복됐지만 자연스러움 지표가 나빠져 채택하지 않았다.

### TPO: GRPO로 구조적 제약 보정

TPO는 season·time·place 같은 추가 슬롯까지 검사해야 해서 같은 방식이 통하지 않았다. 팀은 DPO로 문구 품질을 먼저 학습시키고, 실제 생성 중 발견되는 JSON 파싱 실패·길이 초과·어미 위반 등에 차등 보상을 주는 GRPO(Group Relative Policy Optimization) 단계로 형식만 보정했다. TPO 홀드아웃 형식 통과율은 **DPO 37.6% → DPO+GRPO 62.3%**로 24.7%p 올랐으나, SFT 76.4%에는 미치지 못했다. 형식만 최적화하는 더 강한 설정도 가능했지만 자연스러움 손실 때문에 보수적인 조합을 채택했다.

### 홀드아웃 실험 결과 비교

**WHO 카드:** 모든 NLL 값은 낮을수록 해당 프록시 기준으로 좋으며, 형식 통과율과 함께 살펴야 한다.

| 설정 | 형식 통과율 | 자연스러움 nll_nat↓ | 문맥적합 nll_ctx↓ |
| --- | ---: | ---: | ---: |
| SFT | 86.7% | 3.672 | 3.127 |
| DPO | 62.8% | 3.096 | 2.715 |
| formatmix 0.20 | 70.8% | 3.121 | 2.752 |
| **formatmix 0.25 (채택)** | **76.0%** | **3.096** | **2.738** |
| formatmix 0.50 | 82.8% | 3.151 | 2.787 |

![WHO 카드 홀드아웃 형식 통과율 NLL 그래프](https://oliveyoung.tech/_img/d41edec8c1f34e3d-1024.webp)

*그림 3. WHO 홀드아웃: 형식 통과율과 NLL 분포를 함께 비교한 실험 결과 — [출처: 올리브영 테크블로그](https://oliveyoung.tech/2026-09-18/oy_sllm_alignment/)*

DPO는 자연스러움 지표를 개선했지만 통과율은 23.9%p 떨어졌다. formatmix 0.25는 DPO 대비 형식을 13.2%p 회복하면서 자연스러움 중앙값 3.096을 유지해 채택되었다. 형식 통과율이 가장 높은 변형을 선택한 것은 아니다.

**TPO 카드:** 구조화된 슬롯 조건이 많아 WHO와 동일한 formatmix 접근만으로는 충분하지 않았다.

| 설정 | 형식 통과율 | 자연스러움 nll_nat↓ | 문맥적합 nll_ctx↓ |
| --- | ---: | ---: | ---: |
| SFT | 76.4% | 3.344 | 2.904 |
| DPO | 37.6% | 2.871 | 2.621 |
| **DPO + GRPO (채택)** | **62.3%** | **3.011** | **2.594** |

![TPO 카드 GRPO 홀드아웃 형식 통과율 NLL 그래프](https://oliveyoung.tech/_img/a181ec67d94142bb-1024.webp)

*그림 4. TPO 홀드아웃: GRPO 보정 전후 형식 통과율과 NLL 분포의 절충 — [출처: 올리브영 테크블로그](https://oliveyoung.tech/2026-09-18/oy_sllm_alignment/)*

GRPO는 DPO 대비 통과율을 24.7%p 회복했지만 SFT에는 미치지 못했다. 문맥적합 프록시는 DPO보다 개선됐으나 자연스러움 프록시는 다소 악화됐다. 이 두 표는 원문의 **홀드아웃 테스트** 수치이며 본문 첫 문단의 초기 형식 평가 수치와 조건이 달라 직접 비교하지 않는다.

### 사람 평가로 검증한 지표의 한계

평가 지표가 스스로 만든 결과만 높게 평가하는 순환 문제를 점검하려고 형식 검증을 통과한 약 2,000개 출력을 블라인드 사람 평가와 대조했다. 네 평가 셀의 단순 평균 기준 NLL의 Kendall tau-b는 0.145, AUROC는 0.694로 보고되어 일부 상용 LLM 판정보다 정합성이 좋았지만, 순위 상관 자체가 높다고 보기는 어렵다. 이 결과는 '작은 모델이 언제나 큰 모델보다 좋은 판정자'라는 일반적 증거가 아니라 **해당 과제와 데이터에 적용한 검증 결과**로 해석해야 한다.

## 왜 읽을까

LLM 기반 기능에서는 스키마가 유효한 출력, 사실에 맞는 출력, 사용자에게 좋은 출력을 하나의 합격 점수로 묶으면 개선 방향을 잘못 잡기 쉽다. 먼저 기계적으로 판정 가능한 계약 위반을 분리하고, 의미·품질은 별도 지표 및 사람 평가로 보완하는 다층 검증 방식이 실용적이다. 하나의 목표를 높이면 다른 목표가 저하될 수 있으므로 모델 학습뿐 아니라 생성형 AI의 코드·문서 평가에서도 트레이드오프를 기록할 필요가 있다.

**학습 적용 아이디어(제안·미검증):** AI가 작성한 기술 문서는 필수 메타데이터·링크·형식을 자동 검증하고, 원문 사실의 정확성·설계 적합성은 별도 검토 대상으로 두는 평가 체계를 구성해 볼 수 있다. 원문은 상품 추천 생성 모델에 대한 실험이므로 이러한 개발 워크플로 적용의 효과를 입증한 것은 아니다.

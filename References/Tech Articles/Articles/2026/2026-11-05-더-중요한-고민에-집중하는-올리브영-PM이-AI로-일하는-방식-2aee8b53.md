# 더 중요한 고민에 집중하는 올리브영 PM이 AI로 일하는 방식

> [!abstract] 한 줄 정리
> AI를 문서와 화면의 초안·동기화에 사용하고, 정책 결정과 검수는 담당자가 유지하면 여러 기획서의 불일치를 줄일 수 있다.

> 올리브영 테크블로그 · 2026-10-29

## 핵심 내용

- **문제:** 반복적인 트렌드 수집, 지표 집계, 서로 연결된 7개 기획서의 수동 갱신으로 판단보다 정리에 시간이 들었다.
- **접근:** AI 에이전트로 출처별 브리핑을 자동화하고, 지표 집계 규칙을 스킬로 정의해 Apps Script로 시트에 반영했다.
- **수치:** 아침 정보 수집 30분이 브리핑 확인 10분으로, 도메인별 최대 1시간의 주간 집계가 5분으로 단축됐다.
- **구조:** 기존 화면 캡처와 새 화면의 스타일을 결합해 클릭 가능한 프로토타입을 만들고, 정책 설명 번호를 기준으로 7개 기획서를 연동했다.
- **주의점:** AI가 생성·정리하더라도 무엇을 바꾸고 어떤 정책을 적용할지는 PM이 직접 결정하고 검토했다.

## 왜 읽을까

문서 정합성을 개인의 주의력에 의존하지 않고 구조로 해결하는 사례다. AI를 단순 생성 도구가 아니라 반복 작업과 산출물 간 연결을 담당하는 도구로 활용하는 판단을 배울 수 있다.

**프로젝트에 적용 — DevPedia**

- [ ] 모집·지원·승인 요구사항의 정책 정본과 화면별 설명을 연결한다.
- [ ] 정책 하나를 수정했을 때 API 명세·테스트 조건·화면 설명에 반영되는지 확인한다.
- [ ] AI가 만든 초안은 도메인 불변식과 권한 규칙을 직접 검수한다.

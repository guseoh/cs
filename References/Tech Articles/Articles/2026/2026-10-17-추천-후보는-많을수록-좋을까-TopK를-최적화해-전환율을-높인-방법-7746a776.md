# 추천 후보는 많을수록 좋을까? TopK를 최적화해 전환율을 높인 방법

> [!abstract] 한 줄 정리
> 추천 후보를 많이 가져오는 것이 반드시 좋은 것은 아니다. 전체 후보 예산을 가치가 높은 모델에 재배분하고, 오프라인 예측뿐 아니라 실제 구매·수익·다양성 지표로 검증해야 한다.

> 토스 기술 블로그 · 토스 Commerce Personalization Team · 2026-10-01

## 핵심 내용

추천 시스템은 후보를 더 많이 수집할수록 실제 추천 품질이 좋아진다고 단정할 수 없다. 토스의 Retrieval 단계에서 후보를 무작정 늘리면 Ranking과 광고 검증에 드는 비용이 함께 증가하며, 반대로 모든 모델의 TopK를 똑같이 줄이면 어떤 모델만 제공하던 가치 높은 후보가 먼저 사라질 수 있다.

모델별 TopK를 배분하는 정수계획법은 후보 전체 수의 상한, 각 모델의 최소 확보량, 상위 순위부터 연속 선택이라는 조건을 함께 둔다. 목적 함수는 랭커가 기록한 pCTR × pCVR 기반의 예상 가치를 사용했다. 단순 축소, 정수계획법과 Maximum Coverage를 7일간 온라인 비교하고 User CVR·사용자당 주문 수를 목표 지표로, RPU를 가드레일로 분리한 이유는 전환 수만 높이는 실험이 매출을 악화시킬 수 있기 때문이다.

| 검증 지표(정수계획법 실험) | 변화 | 평가 역할 |
| --- | ---: | --- |
| User CVR | +7.552% | 주요 성공 지표 |
| 사용자당 주문 수 | +10.133% | 주요 성공 지표 |
| CVR / RPU | +13.496% / +0.832% | 전환 및 매출 가드레일 |
| CTR | -3.710% | 사용자 반응의 악화 |
| 고유 노출 상품 수 | -22.07% | 다양성과 노출 범위 비용 |
| 일괄 TopK 1/4 | RPU -3.98%, AOV -5.73% | 단순 축소안 기각 근거 |

*수치는 원문의 특정 7일 온라인 실험 결과이며 다른 추천 시스템에서도 같은 효과가 난다고 일반화할 수 없다.*

후보를 약 절반 줄인 정수계획법에서 User CVR +7.552%, 사용자당 주문 수 +10.133%, CVR +13.496%, RPU +0.832%를 기록했다. CTR은 -3.710%, 고유 노출 상품 수는 -22.07%가 되었으므로 단순한 '전체 지표 개선'이라고 부르기 어렵다. 단순 1/4 축소는 구매 지표가 더 좋았어도 RPU -3.98%, AOV -5.73%라는 부정적 결과 때문에 채택하지 않았다. 실험 목표와 가드레일을 미리 정하지 않았다면 다른 결론에 도달할 수 있었다.

## 왜 읽을까

한 지표의 최고점보다 목표 지표와 수익성·다양성의 균형을 중시하는 실험 설계를 배울 수 있다. 최적화가 만든 새로운 부작용을 후속 실험의 목표로 바꾸는 과정도 유용하다.

**프로젝트에 적용 — FutMatch**

- [ ] 경기 탐색 목록의 후보 수·정렬 조건과 조회 비용·응답시간을 함께 측정한다.
- [ ] 후보 수를 제한한다면 검색 성공률과 노출 다양성이 나빠지지 않는지 확인한다.
- [ ] ML을 바로 도입하기보다 현재 데이터로 검증 가능한 목표 지표와 가드레일을 먼저 정의한다.

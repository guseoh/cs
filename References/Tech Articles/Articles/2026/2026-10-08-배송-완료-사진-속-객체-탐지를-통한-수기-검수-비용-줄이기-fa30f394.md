# 배송 완료 사진 속 객체 탐지를 통한 수기 검수 비용 줄이기

> [!abstract] 한 줄 정리
> 모든 사진을 사람이 검수하거나 처음부터 라벨링하지 않고, 모델이 만든 가짜 라벨에서 틀린 부분만 수정·재학습하는 루프로 검수 비용을 크게 줄였다.

> 컬리 기술 블로그 · 2025-10-27

## 핵심 내용

컬리는 배송 완료 사진에서 퍼플 박스·종이봉투 없이 상품이 놓인 사례를 사람의 눈으로 검수하고 있었다. 사진의 물체를 YOLOv11로 탐지하면 사람이 볼 대상을 줄일 수 있지만, 자동으로 만든 바운딩 박스가 틀린 채로 학습 데이터에 다시 들어가면 모델이 같은 오류를 강화할 수 있다.

![Pseudo Label 생성 결과 검증 수정자와 재학습에 연결되는 Active Learning 구조](https://helloworld.kurly.com/_astro/alc.Bw4_7i6c_18QiWW.webp)

*그림 1. 컬리 원문 라벨 개선 주기: 결과 검증자와 세부 수정자가 다른 비용의 작업을 수행 — [출처: 원문 기술 블로그](https://helloworld.kurly.com/blog/2025-delivery-photo-object-detection/)*

![퍼플 박스와 종이봉투 모델 재학습 전후 Precision Recall 성능표](https://helloworld.kurly.com/_astro/result_table.CUiqMfHl_Zk83Bd.webp)

*그림 2. 원문 모델 성능 비교: 높은 precision뿐 아니라 recall 회복이 중요 — [출처: 원문 기술 블로그](https://helloworld.kurly.com/blog/2025-delivery-photo-object-detection/)*

기존 모델로 Pseudo Label을 만든 뒤 결과 검증자(Result Validator)가 맞음/틀림을 빠르게 분류하고, 틀린 일부만 세부 수정자(Detail Corrector)가 바운딩 박스를 고친다. 개선된 라벨을 다시 학습 데이터에 합쳐 모델을 재학습하는 데이터 중심(Active Learning) 순환 구조다. 높은 confidence의 예측도 틀릴 수 있어 검증을 완전히 생략하기보다 실제 오류의 분포와 사람의 수정 비용을 관측해야 한다.

| 탐지 객체 | 초기 Precision / Recall | 재학습 후 Precision / Recall | 직접 수정 라벨 |
| --- | --- | --- | ---: |
| 퍼플 박스 | 0.9891 / 0.8677 | 0.9992 / 0.9792 | 7% |
| 종이봉투 | 0.8334 / 0.7605 | 0.9694 / 0.9258 | 6% |

*93%와 99.8%의 수기 검수 감소는 단계가 다른 운영 관측값이므로 같은 테스트 세트의 모델 성능 수치와 혼합하지 않는다.*

퍼플 박스의 precision/recall은 0.9891/0.8677→0.9992/0.9792, 종이봉투는 0.8334/0.7605→0.9694/0.9258로 개선됐고 직접 바운딩 박스를 수정한 비율은 각각 7%와 6%였다. 수기 검수 비용은 93% 줄었고, 비닐 상태 배송까지 탐지한 추가 운영 단계에서는 수기 검수 필요 건 99.8% 감소 및 해당 배송 건 25% 감소를 보고했다. 모델 지표의 개선과 실제 배송 품질의 변화는 서로 다른 운영 지표로 구분해야 한다.

## 왜 읽을까

AI 도입 성과를 모델 정확도만으로 평가하지 않고 **사람의 실제 검수 작업량과 서비스 품질**까지 연결한 사례다. 모든 데이터를 재라벨링하기보다 오류 후보에 검수 자원을 집중하는 접근과 높은 확신의 오답 위험을 함께 볼 수 있다.

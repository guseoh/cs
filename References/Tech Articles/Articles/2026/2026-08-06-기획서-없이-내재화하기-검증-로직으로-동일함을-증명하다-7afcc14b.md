# 기획서 없이 내재화하기: 검증 로직으로 동일함을 증명하다

> [!abstract] 한 줄 정리
> 대규모 리팩터링과 내재화의 성공은 새 코드가 완성됐는지가 아니라 기존 시스템과 결과가 동일한지를 자동으로 증명할 수 있느냐에 달려 있습니다.

> techblog.lycorp.co.jp

## 핵심 내용

기획서와 기존 코드까지 확인하기 어려운 외부 시스템을 내재화하면서 동일 입력을 기존·신규 시스템에 주입하고 API 응답, DB 변경 결과, 전체 처리 건수를 비교하는 검증 파이프라인을 만들었습니다. 수천만 건 카탈로그와 수억 건 상품을 수작업으로 확인할 수 없어 CDC와 Kafka를 이용해 실시간 비교했고, 비동기 시간차로 생기는 일시적 불일치는 재시도 후에도 다를 때만 실제 차이로 판정했습니다.

## 왜 읽을까

마이그레이션을 테스트 코드만의 문제가 아니라 운영 데이터와 비동기 흐름까지 포함한 결과 비교 문제로 바라보게 해줍니다.

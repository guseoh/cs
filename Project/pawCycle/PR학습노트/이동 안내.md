# PawCycle PR 학습 노트 — 이동 안내

이 폴더는 `guseoh/pawcycle-commerce` 저장소의 `docs/learning/**`을 2026-11-14에 옮긴 것이다. 파일 내용은 원본 커밋 [`b3b2235d`](https://github.com/guseoh/pawcycle-commerce/tree/b3b2235db1d0b36f79b93ae6db3daa2b8e25a98b/docs/learning)과 같다. 218개 파일의 Git blob 해시가 모두 일치하는 것을 확인했다.

## 무엇이 들어 있나

- `pull-requests/2026/PR-*.md`: PR #1~#216 무렵 병합된 PR마다 자동으로 만든 기록이다. 작업 ID, 변경 파일, 리뷰 결과 같은 PR 메타데이터를 담고 있다.
- `README.md`, `learning-template.md`: 원래 저장소에서 쓰던 학습 기록 안내와 템플릿이다. 당시 규칙을 보존하려고 그대로 두었다.

## 왜 옮겼나

- 이 기록을 만들던 병합 직후 자동 exporter는 이미 retire됐다. 2026-09-06 이후 새 파일이 생기지 않았다.
- 제품 코드, CI, 다른 문서는 이 파일들을 참조하지 않는다. 새 PR의 권위 기록은 GitHub PR 자체다.
- PawCycle 저장소에는 현재 작업 기준 문서와 작업 증거(보고서·ADR)만 두기로 했다. 학습·회고 자료는 이 Vault의 `Project/pawCycle`에 모은다.

결정 기록은 [PWC-0130](../../../Wiki/decisions/PWC-0130.md)에 있다.

## 읽을 때 주의할 점

- 각 노트는 **작성 당시의 PR 기록**이다. 현재 코드나 운영 상태를 뜻하지 않는다.
- 노트 안의 GitHub 링크는 원래 PR과 커밋을 가리키므로, 폴더를 옮긴 뒤에도 그대로 동작한다.
- 원래 경로의 이력은 PawCycle 저장소의 Git 이력에 남아 있다.

# 구현 순서와 작업별 완료 조건

각 작업은 입력, 업무 처리, 저장, 응답, 화면 연결과 검증을 함께 완료한다. 선행 작업이 완료된 뒤 진행하며, 아래 참고 번호는 문서 번호이다.

## 1. 개발 환경과 공통 처리

- 선행 작업 — 없음
- 진행 내용 — 개발·테스트 데이터베이스를 분리하고 초기 데이터, 오류 응답, 인증 요청 보호를 준비한다.
- 완료 확인 — 빈 테스트 데이터베이스에서 초기 구성과 기동 성공을 확인한다.
- 참고 문서 — 01·03·06·07

## 2. 회원과 인증

- 선행 작업 — 개발 환경과 공통 처리
- 진행 내용 — 가입·로그인·로그아웃·내 계정을 연결한다.
- 완료 확인 — 두 계정 로그인, 중복 가입 차단, 로그아웃 후 접근 차단을 확인한다.
- 참고 문서 — 02·04·05·07·09

## 3. 역할·기술과 프로필

- 선행 작업 — 회원과 인증
- 진행 내용 — 기준정보 조회와 공개·본인 프로필 관리를 구현한다.
- 완료 확인 — 공개 개인정보 차단과 선택 항목 검증을 확인한다.
- 참고 문서 — 02·03·04·05

## 4. 모집글 작성과 기본 조회

- 선행 작업 — 역할·기술과 프로필
- 진행 내용 — 글·역할·정원을 함께 저장하고 상세와 기본 목록을 연결한다.
- 완료 확인 — 잘못된 일정·정원을 거절하고 일부 저장 실패 시 전체 취소를 확인한다. 승인 수와 북마크 상태의 최종 검증은 후속 작업에서 수행한다.
- 참고 문서 — 02·03·04·05

## 5. 지원 제출·조회·철회

- 선행 작업 — 모집글 작성과 기본 조회
- 진행 내용 — 역할별 지원, 제출 링크 보존, 본인 이력 조회와 철회를 연결한다.
- 완료 확인 — 날짜 경계, 동시 중복 지원 차단, 철회 후 재지원을 확인한다.
- 참고 문서 — 02·04·05·09

## 6. 선발과 모집 마감

- 선행 작업 — 지원 제출·조회·철회
- 진행 내용 — 승인·거절, 역할 충족 시 남은 지원 종료, 전체 정원 충족과 직접 마감을 함께 구현한다.
- 완료 확인 — 마지막 자리 동시 승인, 승인·철회 경합, 마감·지원 경합과 상세 승인 인원을 확인한다.
- 참고 문서 — 02·04·06·09

## 7. 모집글 수정과 공개 제거

- 선행 작업 — 선발과 모집 마감
- 진행 내용 — 지원 이력에 따른 수정 제한과 공개 제거를 구현한다. 내 모집에 공개 범위 필터를 연결한다.
- 완료 확인 — 지원이 먼저 확정되면 일정·정원 수정이 거절된다. 수정이 먼저 확정되면 지원은 변경 조건으로 판단한다. 제거 후 공개 차단과 모집자·지원자 이력 조회를 확인한다.
- 참고 문서 — 02·04·05·09

## 8. 검색과 목록 완성

- 선행 작업 — 모집글 수정과 공개 제거
- 진행 내용 — 검색·필터·정렬·페이지와 전체 건수를 일치시킨다.
- 완료 확인 — 빈 결과, 마지막 페이지, 공개 제거 필터와 건수 일치를 확인한다.
- 참고 문서 — 04·05·09

## 9. 댓글과 답글

- 선행 작업 — 모집글 수정과 공개 제거
- 진행 내용 — 한 단계 답글과 부모 미리보기, 작성·수정·삭제를 연결한다.
- 완료 확인 — 부모 삭제·답글 작성 경합, 마감 후 기존 댓글 관리, 제거된 글의 댓글 수정 차단을 확인한다.
- 참고 문서 — 02·04·05·09

## 10. 북마크와 상세 완성

- 선행 작업 — 모집글 수정과 공개 제거
- 진행 내용 — 추가·해제·목록과 상세의 내 북마크 상태를 연결한다.
- 완료 확인 — 중복 추가, 없는 항목 해제, 제거 글 제외 및 로그인 여부별 상세 응답을 확인한다.
- 참고 문서 — 02·04·05·09

## 11. 전체 흐름 검증

- 선행 작업 — 앞선 모든 작업
- 진행 내용 — 서로 다른 두 계정으로 모집부터 결과 확인까지 진행한다.
- 완료 확인 — 브라우저 흐름, 권한, 오류·빈 화면, 키보드 조작과 회귀 검증 결과를 기록한다.
- 참고 문서 — 00·07·09

## 공통 완료 조건

정상 처리, 입력 오류, 본인·타인 권한, 데이터 반영과 실패 시 취소를 확인한다. 시간 경계는 고정 시각으로 검증하며 동시 요청은 서로 독립된 연결에서 실행한다. 실제 실행 결과를 기록한다.

## 후속 범위

알림, 합류 후 연락, 계정 복구, 소셜 로그인, 모집 재개는 차기 후보이다.

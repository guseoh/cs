# ERD 검토 결과

## 전체 물리 ERD 배치

11개 테이블을 각각 한 번 표시하는 통합 도면이다. 회원·모집글·지원서를 가운데에 두고, 댓글은 회원 옆에, 기준 역할·모집 정원은 위쪽에, 기술 스택과 연결 테이블은 아래쪽에 배치했다. 북마크는 회원과 모집글 가까이에 배치했다. 관계선은 테이블 사이의 공간으로 연결하며 테이블 내부를 통과하지 않는다.

## 관계 표현

18개 외래키 관계를 유지한다. 실선은 식별 관계, 점선은 비식별 관계이다. 부모의 필수·선택 여부와 자식의 다수 여부를 표시한다. 회원에서 지원서로 향하는 두 관계는 지원자와 처리자로 구분했다. 관계선의 교차는 연결을 뜻하지 않는다.

관계선은 테이블 경계에 연결되므로 접점 옆의 컬럼을 외래키로 해석하지 않는다. 원본 SVG 또는 ERD 탐색 화면에서 선에 마우스를 올리면 정확한 부모·자식 컬럼 묶음을 확인할 수 있다. 복합 외래키도 하나의 관계로 표시한다. 복합 유일 제약·검사 제약·인덱스·자동 번호 정책은 데이터베이스 문서에 따른다.

## 화면과 검증

물리 ERD는 2360×1410의 가로형 구성이다. 탐색 화면은 물리 ERD 전체를 화면에 맞춰 보여주며 확대·축소·원본 크기를 제공한다. 작은 화면에서 컬럼의 세부 내용은 확대해서 읽는다. 논리 ERD는 기존 통합 배치이다.

원본 대비 11개 테이블, 66개 컬럼의 이름·키 표시·타입·NULL 허용 여부, 18개 외래키의 부모·자식 컬럼 묶음이 일치함을 검증했다. 관계선이 테이블 내부를 통과하지 않음을 검사했다. 밝은 배경 1888×1128, 어두운 배경 1416×846의 전체 도면을 렌더링하여 배치와 글자 겹침을 확인했다. 실제 데이터베이스 실행은 별도 검증 사항이다.

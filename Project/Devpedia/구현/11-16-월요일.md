

## 1-3 Clock·감사 설정

회원이나 모집글을 저장할 때마다 다음 작업을 서비스에 직접 작성할 수 있다.
```text
createdAt = 현재시각;
updatedAt = 현재시각;
```
수정할 때는 `updatedAt`만 바꿔야 합니다. 이런 작업을 모든 서비스에서 반복하면 누락되거나 서로 다른 시간 기준을 사용할 수 있습니다.

| 클래스                                                    | 책임                           |
| ------------------------------------------------------ | ---------------------------- |
| [`ClockConfig`](idea://symbol/ClockConfig)             | 현재 시각을 얻을 객체를 Spring에 등록     |
| [`JpaAuditingConfig`](idea://symbol/JpaAuditingConfig) | JPA 감사 기능을 켜고 사용할 시간 공급자를 지정 |
| [`BaseTimeEntity`](idea://symbol/BaseTimeEntity)       | 자동으로 기록할 필드와 DB 매핑을 선언       |
**감사(Auditing)** 는  생성·수정 시각 같은 정보를 기록하는 기능을 뜻한다. 


#### ClockConfig

```Java
@Configuration
public class ClockConfig {

    @Bean
    public Clock clock() {
        return Clock.systemUTC();
    }
}
```
- `ClockConfig`: 현재 시각을 얻을 객체로 등록한다.
- 이 코드는 “현재 시각을 구할 때 사용할 `Clock`객체를 만들어 Spring에 등록한다”는 의미이다. [Spring의 Java 설정 문서](https://docs.spring.io/spring-framework/reference/core/beans/java/basic-concepts.html)

[`Clock`]()은 Spring 전용 클래스가 아닌 Java 표준 API이다. `Clock.systemUTC()`
가 반환하는 객체에 `instant()`를 호출하면 실제 시스템의 현재 시각을 얻는다.
```cardlink

```
- `Clock` 객체: 현재 시각을 얻는 수단
- `Instant`: 특정한 한 시점의 값

#### JpaAuditingConfig

```java
@Configuration  
@EnableJpaAuditing(  
        dateTimeProviderRef = "auditingDateTimeProvider",  
        modifyOnCreate = true  
)  
public class JpaAuditingConfig {  
  
    @Bean  
    public DateTimeProvider auditingDateTimeProvider(Clock clock) {  
        return () -> Optional.of(  
                LocalDateTime.ofInstant(clock.instant(), ZoneOffset.UTC)  
        );  
    }  
  
}
```
- `JpaAuditingConfig`: 감사 기능에 Clock을 연결한다.
- `@EnableJpaAuditing`은 생성·수정 시각을 자동 처리할 Spring Data JPA의 기반 기능을 등록한다.
	- `dateTimeProviderRef` : `auditingDateTimeProvider`라는 Bean에서 감사 시각을 얻는다.
	- `modifyOnCreate = true`: 최초 생성 시 수정 시간도 함께 기록

`modifyOnCreate = true`이므로 최초 저장 시 [`createdAt`](idea://symbol/createdAt)과 [`updatedAt`](idea://symbol/updatedAt)을 모두 채웁니다. 설계의 두 컬럼이 모두 `NOT NULL`인 것과도 맞습니다.


```java
@Bean
public DateTimeProvider auditingDateTimeProvider(Clock clock) {
    return () -> Optional.of(
            LocalDateTime.ofInstant(clock.instant(), ZoneOffset.UTC)
    );
}
```
- 매개변수 `Clock clock`은 Spring이 채운다. Spring이 이 Bean을 생성할 때 등록된 `Clock` 타입의 Bean을 찾아 전달한다. 
	- 앞에서 `ClockConfig` 가 등록한 객체가 여기 들어간다. 이것이 [의존성 주입]{의존성 주입은 필요한 객체를 직접 만들지 않고 외부에서 전달받는 방식이며, 현재 코드에서는 Spring 컨테이너가 `Clock` Bean을 찾아 `auditingDateTimeProvider()`에 전달하는 과정}이다.

반환 타입인 `DateTimeProvider`는 Spring Data가 감사 시각을 요청할 때 사용하는 인터페이스입니다. 핵심 메서드는 다음 형태이다.
```java
Optional<TemporalAccessor> getNow();
```
- [이름 그대로 “지금 시각을 제공하라”는 역할](https://docs.spring.io/spring-data/commons/docs/current/api/org/springframework/data/auditing/DateTimeProvider.html)이다.

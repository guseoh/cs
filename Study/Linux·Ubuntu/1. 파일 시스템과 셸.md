## 1. Linux 파일 시스템과 경로

Linux는 루트 디렉터리(`/`) 를 시작점으로 하는 하나의 디렉터리 계층을 사용한다. 다른 디스크나 파일 시스템도 특정 디렉터리에 마운트하여 같은 경로 구조에서 접근할 수 있다.

![[Pasted image 20261109143806.png|Linux 디렉터리 구조 참고|350]]

| 경로         | 핵심 역할         |
| ---------- | ------------- |
| `/`        | 최상위 디렉터리      |
| `/home`    | 사용자 홈 디렉터리    |
| `/etc`     | 시스템 설정 파일     |
| `/usr/bin` | 명령어 및 실행 프로그램 |
| `/var`     | 로그 및 캐시       |
| `/tmp`     | 임시 파일         |
| `/proc`    | 프로세스 및 커널 정보  |
| `/mnt`     | 파일 시스템 마운트 위치 |

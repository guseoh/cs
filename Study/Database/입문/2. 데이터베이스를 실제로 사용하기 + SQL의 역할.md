## 1. 데이터베이스를 사용한다는 것은 서버에 접속해서 명령을 요청한다는 뜻

IntelliJ에서 Java 프로그램을 실행할 때는 JVM 프로세스가 실행되고, 브라우저에서 Spring 서버에 요청을 보내면 실행 중인 Spring Boot 프로세스가 그 요청을 처리한다. MySQL도 마찬가지다. **데이터베이스 파일을 직접 열어서 읽고 쓰는 것이 아니라, 실행 중인 MySQL Server 프로세스에 접속해서 작업을 요청한다.**

MySQL 핵심 서버 프로그램은 `mysqld`다. `ysql` 명령줄 프로그램, MySQL Workbench, DBeaver, 백엔드 애플리케이션 등은 MySQL Server에 연결하는 **클라이언트(Client)** 역할을 한다.

## 2. SQL은 무언인가?

SQL은 **Structured Query Language**, 즉 관계형 데이터베이스의 데이터를 정의하고 조회하고 변경하기 위한 언어다.
MySQL, PostgreSQL, Oracle, SQL Server처럼 서로 다른 RDBMS들도 SQL을 중심 인터페이스로 사용한다.

SQL은 기본적으로 **선언형(Declarative)** 언어다.

```java
for (Order order : orders) {
    if (order.getStatus() == PAID) {
        result.add(order);
    }
}
```
- Java에서는 개발자가 직접 처리 방법(How)까지 지정한다. 

```sql
SELECT id, total_amount
FROM orders
WHERE status = 'PAID';
```
- SQL에서는 "`orders` 중 `status = 'PAID'`인 행에서 `id`, `total_amount`를 달라." 라고 **원하는 결과(What)**를 표현한다.
- 즉, Java와 달리 구체적인 실행 절차가 적혀 있지 않다.

그래서 SQL을 잘 작성한다는 것은 **내가 어떤 결과 집합을 요구하고 있는지 이해하고, DBMS가 그 결과를 만들기 위해 어떤 작업을 할 가능성이 있는지를 생각할 수 있어야 한다.**

## 3. 핵심 흐름

```
MySQL Server가 실행 중이다
        ↓
Client가 Server에 연결한다
        ↓
인증과 권한 확인을 거친다
        ↓
작업할 Database를 선택한다
        ↓
SQL로 원하는 작업을 요청한다
        ↓
DBMS가 SQL을 해석하고 실행 방법을 결정한다
        ↓
데이터를 읽거나 변경한다
        ↓
결과 또는 성공/실패 상태를 Client에 반환한다
```

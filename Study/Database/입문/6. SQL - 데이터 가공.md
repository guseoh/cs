## 1. 산술 연산 - 저장된 값으로 새로운 정보를 계산한다

| id  | name    | price | stock | category |
| --- | ------- | ----- | ----- | -------- |
| 1   | 텀블러     | 15000 | 5     | 생활       |
| 2   | 머그컵     | 9000  | 12    | 생활       |
| 3   | 키보드     | 45000 | 3     | 전자       |
| 4   | 마우스     | 25000 | 0     | 전자       |
| 5   | 노트북 거치대 | 30000 | 7     | `NULL`   |
| 6   | USB 허브  | 15000 | 10    | 전자       |
- 상품마다 가격과 재고 수량은 저장되어 있지만, 현재 보유한 상품의 재고 금액은 별도로 저장하지 않았다.
- 예를 들어 텀블러는 가격이 15,000원이고 재고가 5개이므로 `15000 x 5 = 75000`원이라는 값을 계산할 수 있다.

```sql
SELECT
    id,
    name,
    price,
    stock,
    price * stock AS stock_value
FROM products
WHERE id IN (1, 2, 5);
```
- 각 상품의 가격과 재고 수량을 곱해서 `stock_value`라는 결과 컬럼을 만든다.

여기서 `price * stock`을 **표현식(Expression)** 이라고 한다. 컬럼이나 상수에 연산자를 적용해 새로운 값을 만들어내는 구문이다.

`AS stock_value`는 표현식의 결과에 붙이는 별칭(Alias)이다. 이 별칭을 붙이지 않아도 계산은 되지만, 조회 결과를 받는 개발자에게 해당 값이 어떤 의미인지 명확하게 알려줄 수 있다.

**계산된 `stock_value`는 조회 결과에만 존재하는 값이지, 실제 `products` 테이블에 새로운 컬럼이 생긴 것이 아니다.**

#### 숫자를 계산할 때 알아두면 좋은 함수

| 함수 또는 연산자 | 의미 | 사용 예와 결과 |
|---|---|---|
| `+`, `-`, `*` | 덧셈·뺄셈·곱셈 | `100 * 3` → `300` |
| `/` | 나눗셈 | `5 / 2` → `2.5000` |
| `DIV` | 정수 나눗셈 | `5 DIV 2` → `2` |
| `MOD(a, b)` | 나머지 | `MOD(5, 2)` → `1` |
| `ROUND(n, d)` | 지정 자릿수로 반올림 | `ROUND(12.345, 2)` → `12.35` |
| `TRUNCATE(n, d)` | 지정 자릿수 아래를 버림 | `TRUNCATE(12.345, 2)` → `12.34` |
| `CEIL(n)` | 크거나 같은 가장 가까운 정수 | `CEIL(12.1)` → `13` |
| `FLOOR(n)` | 작거나 같은 가장 가까운 정수 | `FLOOR(12.9)` → `12` |
| `ABS(n)` | 절댓값 | `ABS(-5)` → `5` |

#### 실무에서는 반올림 방식과 숫자 타입을 함께 생각해야 한다

```sql
SELECT
    name,
    price,
    ROUND(price * 0.9, 0) AS discounted_price
FROM products;
```
- 모든 상품 가격에 10% 할인율을 적용한 예상 가격을 조회
- `price * 0.9`로 할인 가격을 계산하고, `ROUND(…, 0)`으로 소수점 이하를 반올림한다.

반올림 했다는 것만으로 실제 결제에 필요한 모든 금액

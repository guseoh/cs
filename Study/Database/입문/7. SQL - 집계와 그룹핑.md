## 1. 집계 함수는 여러 행에서 하나의 결과를 계산한다

| id  | name    | price | stock | status   | category |
| --- | ------- | ----: | ----: | -------- | -------- |
| 1   | 텀블러     | 15000 |     5 | SALE     | 생활       |
| 2   | 머그컵     |  9000 |    12 | SALE     | 생활       |
| 3   | 키보드     | 45000 |     3 | SALE     | 전자       |
| 4   | 마우스     | 25000 |     0 | SOLD_OUT | 전자       |
| 5   | 노트북 거치대 | 30000 |     7 | SALE     | `NULL`   |
| 6   | USB 허브  | 15000 |    10 | SALE     | 전자       |
이 테이블에서 전체 상품이 몇 개인지 알고 싶다면 Java에서 모든 상품을 조회해 `List` 의 크기를 구할 수 있다. 하지만 행 개수만 필요한데 모든 상품 정보를 네트워크로 가져오는 것은 불필요한 작업이다.

MySQL은 **`COUNT()`를 사용해 행의 개수를 직접 계산**할 수 있다.
```sql
SELECT COUNT(*) AS total_products
FROM products;
```
- `COUNT(*)`는 `products`의 개별 상품 정보를 반환하는 것이 아니라, 조회 대상에 해당하는 **행의 개수**를 계산한다.

이렇게 집계 함수를 사용하면 **여러 행에 저장된 데이터로부터 하나의 요약 값**을 구할 수 있다. `GROUP BY` 없이 집계 함수를 사용한 경우에는 조건을 통과한 행 전체가 하나의 집계 대상이 된다.

### COUNT, SUM, AVG, MIN, MAX는 무엇을 계산할까?
| 함수              | 역할             | 대표적인 사용       |
| --------------- | -------------- | ------------- |
| `COUNT(*)`      | 행의 개수          | 전체 주문 수       |
| `COUNT(column)` | NULL이 아닌 값의 개수 | 이메일이 등록된 회원 수 |
| `SUM(column)`   | 값들의 합계         | 총 재고 수량       |
| `AVG(column)`   | 값들의 평균         | 평균 상품 가격      |
| `MIN(column)`   | 최솟값            | 가장 낮은 상품 가격   |
| `MAX(column)`   | 최댓값            | 가장 높은 상품 가격   |
집계 함수의 또 다른 특징은 **집계 함수 안에 컬럼뿐 아니라 계산식도 사용할 수 있다.**

예를 들어 `SUM(price * stock)`은 각 상품 행에서 가격과 재고 수량을 곱한 다음 그 계산 결과를 모두 더한다.

### `COUNT(*)`와 `COUNT(column)`은 왜 결과가 다를까?

```sql
SELECT
    COUNT(*) AS total_count,
    COUNT(category) AS categorized_count,
    COUNT(DISTINCT category) AS category_types
FROM products;
```
|total_count|categorized_count|category_types|
|---|---|---|
|6|5|2|

`COUNT(*)`는 행 자체의 개수를 세기 때문에 `category`가 `NULL`인 상품도 포함해 6이 된다.

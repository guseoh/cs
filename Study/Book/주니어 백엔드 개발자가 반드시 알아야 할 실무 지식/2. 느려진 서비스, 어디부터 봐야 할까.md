## 응답 시간

응답 시간은 **사용자의 요청을 처리하는 데 걸리는 시간**을 의미한다.

> [!more]- API 호출 과정
> 
> ```mermaid
> sequenceDiagram
>     participant APP as 앱
>     participant API as API 서버
>     participant DB as DBMS
> 
>     APP->>API: 1. API 요청
>     API->>DB: 1.1 SQL 실행
>     API->>DB: 1.2 SQL 실행
>     API-->>APP: 1.3 JSON 응답
> ```

## 1. 클래스가 필요한 이유

프로그램을 개발하다 보면 하나의 대상을 표현하기 위해 여러 데이터를 함께 관리해야 하는 상황이 발생한다. 

학생을 관리하는 프로그램이라면 이름, 나이, 성적이 필요하고, 쇼핑몰이라면 상품명, 가격, 재고 수량과 같은 데이터가 필요하다.

```java
String student1Name = "학생1";
int student1Age = 15;
int student1Grade = 90;

String student2Name = "학생2";
int student2Age = 16;
int student2Grade = 80;
```
- 학생이 추가될 때마다 이름, 나이, 성적을 저장하는 **변수를 추가**해야 한다.
- 학생이 100명이라면 300개의 변수가 필요하며, 학생 정보를 출력하거나 수정하는 코드도 그에 맞게 늘어난다.

```java
String[] studentNames = {"학생1", "학생2"};
int[] studentAges = {15, 16};
int[] studentGrades = {90, 80};

for (int i = 0; i < studentNames.length; i++) {
    System.out.println(
            studentNames[i] + " " +
            studentAges[i] + " " +
            studentGrades[i]
    );
}
```
- **배열**을 사용하면 반복문을 통해 여러 학생을 처리할 수 있다.
- 하지만 한 학생의 정보가 서로 다른 세 개의 배열에 흩어져 있는 문제가 발생한다.
	- 같은 인덱스를 사용해야만 한 학생의 정보를 올바르게 가져올 수 있다.

![[Attachments/diagrams/java/parallel-arrays.svg|350]]

![[Attachments/diagrams/java/student-data.svg|350]]
근본적인 문제는 학생이라는 하나의 대상을 표현하는 데이터가 하나의 구조로 묶어 있지 않다는 것이다. 

**클래스를 사용하면 관련된 데이터를 하나의 타입으로 정의하고, 객체 단위로 관리할 수 있게 된다.**

## 2. 클래스, 객체, 인스턴스

### 클래스(Class)

객체가 어떤 데이터와 기능을 가질 것인지를 정의하는 구조이며, Java에서 새로운 타입을 만드는 방법이다.

Java에서 제공하는 `int`, `boolean`과 같은 기본형 외에도 개발자가 프로그램에 필요한 `Student`, `Member`, `Order`, `Product` 등의 타입을 직접 정의할 수 있다.

```java
public class Student {

    String name;
    int age;
    int grade;
}
```
- 클래스 내부에 선언된 `name`, `age`, `grade`를 **필드(Field)** 또는 **멤버 변수(Member Variable)** 라고 한다. 위의 필드들은 `static`이 붙어 있지 않으므로 객체마다 독립적으로 존재하는 인스턴스 변수이다.
- **클래스를 정의했다는 것은 객체가 어떤 구조를 가질 것인지를 결정**한 것이다. 아직 실제 데이터를 저장하는 객체를 생성한 것은 아니다.

### 객체(Object)와 인스턴스(Instance)

**클래스를 기반으로 실제 생성된 실체**를 객체라고 한다. 하나의 클래스로 여러 객체를 생성할 수 있으며, 각각의 객체는 자신만의 상태를 가진다. 객체와 인스턴스는 일반적인 Java 프로그래밍에서 거의 같은 의미로 사용된다.
![[Attachments/diagrams/java/class-and-instance.svg|350]]
객체와 인스턴스는 일반적인 Java 프로그래밍에서 거의 같은 의미로 사용된다.

| 용어   | 의미                  | 예시                     |
| ---- | ------------------- | ---------------------- |
| 클래스  | 객체의 데이터와 기능을 정의한 구조 | `Student`              |
| 객체   | 실행 중에 존재하는 실체       | 생성된 학생 객체              |
| 인스턴스 | 특정 클래스로부터 생성된 실체    | `Student`의 인스턴스        |
| 필드   | 클래스에 선언된 변수         | `name`, `age`, `grade` |
| 상태   | 특정 시점에 객체가 가진 데이터   | 학생1, 15, 90            |

클래스는 데이터뿐만 아니라 메서드도 정의할 수 있다. **따라서 클래스는 단순히 여러 변수를 묶는 기능에 그치지 않고, 데이터와 그 데이터를 처리하는 기능**을 함께 정의하는 [객체지향 프로그래밍]{데이터(속성)와 이를 다루는 기능(메서드)을 하나의 '객체'로 묶고, 객체 간 상호작용으로 프로그램을 구성하는 프로그래밍 패러다임}의 기반이 된다.

## 3. 객체의 생성과 사용

```java
Student student1;   
student1 = new Student();

student1.name = "학생1";
student1.age = 15;
student1.grade = 90;

Student student2 = new Student();
student2.name = "학생2";
student2.age = 16;
student2.grade = 80;
```
###### **① 변수 선언 —** `Student student1;` 

![[Pasted image 20261125141902.png|350]]
- `Student` 타입의 참조 변수를 선언한다. 이 변수에는 `Student` 타입에 맞는 객체의 참조값을 저장할 수 있다. 변수만 선언한 상태에서는 실제 학생 객체가 생성되지 않는다.

###### **② 객체 생성 —** `new Student()`
![[Pasted image 20261125141810.png|350]]
- `Student` 클래스에 정의된 구조를 바탕으로 새로운 객체를 생성한다. JVM의 메모리 모델상 **객체는 힙 영역에 할당**되며, 인스턴스 필드를 위한 공간도 함께 확보된다.

###### **③ 참조값 저장 —** `student1 = new Student();`
![[Pasted image 20261125142007.png|350]]
- `new Student()`의 실행 결과인 참조값을 `student1` 변수에 저장한다. 따라서 `student1`에는 객체 전체가 들어 있는 것이 아닌 생성된 객체에 접근하기 위한 값이 들어 있다.

###### **④ 객체 사용 —** `student1.age = 15;`

- 점(`.`) 연산자를 사용하면 참조 변수가 가리키는 객체의 필드나 메서드에 접근할 수 있다.
- `student1.age = 15`는 `student1` 변수 자체의 값을 변경하는 것이 아니라, `student1`이 참조하는 객체 내부의 `age` 필드를 변경하는 코드이다.



###### ✅ 참조값을 변수에 보관해야 하는 이유
객체를 생성하는 `new Student()` 코드 자체에는 아무런 이름이 없다. 이 코드는 단순히 Student 클래스(설계도)를 기반으로 메모리에 실제 객체를 만드는 것이다.

따라서 생성한 객체에 접근할 수 있는 방법이 필요하다. 이런 이유로 객체를 생성할 때 반환되는 참조값을 어딘가에 보관해두어야 한다.

앞서 Student student1 변수에 참조값(x001)을 저장해두었으므로 **저장한 참조값을 통해서 실제 메모리에 존재하는 객체에 접근할 수 있다.**


## 4. 참조 변수와 실제 객체의 차이

![[Attachments/diagrams/java/reference-and-object.svg|350]]

`student1`과 `student2`는 같은 `Student` 타입이지만, 각각 다른 `new Student()` 표현식을 통해 만들어진 객체를 참조한다. 따라서 `student1.grade = 100`을 실행해도 `student2.grade`는 기존 값인 80을 유지한다.

```java
Student student3 = student1;
student3.grade = 100;

System.out.println(student1.grade); // 100
System.out.println(student3.grade); // 100
System.out.println(student2.grade); // 80
```
- 객체를 새로 생성하지 않고 참조 변수를 대입하면 동작이 달라진다.
- `Student student3 = student1`을 실행할 때는 새로운 객체가 생성되지 않는다.
- `student1`에 저장되어 있던 참조값만 복사하여 `student3`에 저장한다.
- **두 변수는 같은 객체를 참조하여, 어느 변수를 통해 필드를 변경하더라도 동일한 객체의 상태가 변경**된다.

![[Pasted image 20261125143611.png|350]]
위 그림에서도 `std1`과 `std2`가 동일한 `Studnet`객체를 참조하고 있다. 또한 `String` 타입의 필드 역시 문자열 객체를 가리키는 참조값을 저장한다는 것을 확인할 수 있다.

| 코드                           | 실제 동작            | 새로운 객체 생성 |
| ---------------------------- | ---------------- | --------- |
| `Student s = new Student();` | 객체를 생성하고 참조값을 저장 | O         |
| `Student s = student1;`      | 기존 객체의 참조값을 복사   | X         |
| `s.grade = 100;`             | 참조하는 객체의 필드 변경   | X         |
| `s = student2;`              | 다른 객체의 참조값으로 변경  | X         |
`s = student2`는 기존 객체의 내용을 수정하는 것이 아니라 변수 `s`가 다른 객체를 가리키도록 변경하는 것이다.

**자바에서 참조값의 변경과 객체 내부 상태의 변경은 서로 다른 동작**이다.

## 5. 클래스와 배열

클래스를 도입하면 학생 한 명의 정보를 하나의 객체로 관리할 수 있다. 하지만 학생이 늘어날 때마다 `student1`, `student2`, `student3`와 같은 변수를 계속 선언한다면 여러 학생을 한꺼번에 처리하기 어려워진다.

```java
Student[] students = new Student[2];

students[0] = student1;
students[1] = student2;
```
- `new Student[2]`는 `Student` 타입의 참조값을 두 개 저장할 수 있는 **배열 객체 하나**를 생성하는 코드이다.
- 배열 생성 직후에는 아직 어떤 학생도 저장하지 않았으므로 각 요소의 값도 `null`이다.

![[Attachments/diagrams/java/reference-array-empty.svg|350]]

![[Attachments/diagrams/java/reference-array-assigned.svg|350]]
`students[0] = student1`을 실행하면 `student1`에 저장되어 있는 참조값이 배열의 첫 번째 요소에 복사된다. 따라서 `students[0]`과 `student1`을 통해 접근하는 객체는 동일하다.

이를 이용하여 여러 학생 객체를 반복문으로 처리할 수 있다.

```java
Student[] students = {student1, student2};

for (Student student : students) {
    System.out.println(
            student.name + " " +
            student.age + " " +
            student.grade
    );
}
```

## 6. 백엔드 개발에서 클래스의 의미

백엔드 개발에서는 클래스를 사용하여 프로그램에서 다루는 데이터를 의미 있는 단위로 표현한다. 예를 들어 주문에 필요한 정보를 개별 변수로 관리하는 대신 하나의 `Order` 타입으로 정의할 수 있다.

```java
public class Order {

    Long id;
    String productName;
    int quantity;
    int price;
}
```

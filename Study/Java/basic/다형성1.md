상속에서 `Child extends Parent`라고 하면 `Child`는 자신의 기능뿐 아니라 `Parent`가 제공하는 기능도 사용할 수 있다. **`Child`객체를 꼭 `Child` 타입으로만 다뤄야 하는 것은 아니고, 부모인 `Parent`타입으로도 다룰 수 있다.**

즉, P`arent parent = new Child()`왜 쓰는지에 대한 이해가 핵심이다.

### 다형성 참조 - 변수의 타입과 실제 객체는 다를 수 있다
```java
Parent poly = new Child();
```
- 변수의 타입과 실제로 만들어진 객체의 타입을 분리해서 봐야 한다.
- 변수 자체의 타입은 `Parent`다. 하지만 `new`로 실제 생성한 객체는 `Child`다.
- `poly` 안에는 `Child` 객체를 가리키는 참조값이 들어 있지만, 그 참조값을 사용하는 창구는 `Parent` 타입이라고 생각하면 된다.
